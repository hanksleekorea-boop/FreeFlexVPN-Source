## 한 문장

여행·공용망에서 공식 WireGuard를 이용해 안전한 인터넷 통로와 무료 1GB 권리를 제공하려는 한국어 우선 소비자 VPN/PWA

## 사용자와 과업

- 핵심 사용자: 해외 체류·여행자, 공용 Wi-Fi 사용자, 한국어 우선 초보 VPN 사용자
- 핵심 과업: 공개 앱 진입 → 지원 범위 이해 → WireGuard 설치 → 설정 가져오기 → VPN 연결 → 보호 상태 확인 → 망 전환 → 사용량 확인 → 실패 복구 → 설정 폐기·삭제
- 흐름: 유입 → 공개 앱 시작 → 제한·무료 권리 이해 → 설정 발급/가져오기 → 첫 연결 → 보호 결과 이해 → 반복 연결·망 전환 → 사용량/지원 → 취소·삭제·이탈

## 실제 범위

- 모바일·PC: 같은 반응형 공개 앱. PWA 파일·브라우저 증거가 있다.
- Android: Android 15 한 대에서 IPv4 출구가 TH→US→TH로 바뀌고 복구됨.
- 미확인: IPv6, 누출, 킬 스위치, 장시간, Windows/iPhone VPN, 결제·환불·운영.
- Kakao Connect: 기존 서비스·무료 권리·프로필을 대체하지 않는 비공개 추가 프로필.
