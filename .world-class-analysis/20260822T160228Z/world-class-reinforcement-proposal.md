# 세계 선두 수준 추격 보강 제안서

## 1. 제품 진단

FreeFlexVPN은 무료 1GB 권리, 공식 WireGuard, 증거 등급 분리, 기존 프로필 보존, 공개 반응형 앱이라는 좋은 정체성을 갖췄다. Android 한 대에서 태국→미국 출구와 복구가 확인됐지만, 실제 보호·누출·기기 수명주기·지원·결제·법률·다중 플랫폼 운영이 한 고객 흐름으로 이어지지 않아 시험 서비스다.

## 2. 강점 5

1. 추정과 실기기 증거를 분리한다.
2. 무료 권리와 기존 프로필을 비하향 계약으로 보호한다.
3. 공식 WireGuard를 사용한다.
4. 모바일·PC·QR·대시보드가 공개돼 있다.
5. 자동 검사와 가상 1,000명 위험 탐색 자산이 있다.

## 3. 중요한 결함 10

1. GAP-001 보호 상태의 외부 근거 결속 — 실기기 미국 출구는 확인됐으나 화면과 서버 악수·DNS·IPv6·누출이 한 증거로 결속되지 않음
2. GAP-008 기기·프로필 수명주기 센터 — 후보 보존 계약은 있으나 사용자용 발급·재발급·폐기·분실 대응이 미완결
3. GAP-009 무료 1GB 권리와 사용량 정합성 — 무료 권리는 확정됐으나 실제 사용량·잔액·소진·오류 원장이 운영 자료와 연결되지 않음
4. GAP-003 킬 스위치·항상 연결 실제 검증 — 화면 안내는 있으나 Android·Windows 상태별 실제 검증이 없음
5. GAP-004 DNS·IPv6·누출 검사 — IPv4 국가 전환은 확인됐지만 IPv6과 누출은 미확인
6. GAP-006 최소 계정·삭제·내보내기 실제 흐름 — 로컬 자료 삭제 안내는 있으나 운영 계정·서버 자료 삭제 왕복 없음
7. GAP-010 결제·취소·환불·복원 — 가격 미확정이며 실제 결제 왕복 0건
8. GAP-011 고객지원·상태판·장애 훈련 — 개발 대시보드는 있으나 고객 상태판·응답 기준·훈련 증거 없음
9. GAP-017 개인정보 사실표·관할·국외이전 — 초안은 있으나 운영 주체·실제 처리자·보유·삭제·국외 이전 확정 없음
10. GAP-002 첫 연결과 설정 발급의 종단 흐름 — 공개 UI와 WireGuard 실제 동작 사이 설정 발급·만료·복구가 사용자 흐름으로 완결되지 않음

## 4. 놓친 사용자 결과

보호됨을 스스로 확인, 실패 1분 복구, 기기별 설정 폐기, 실제 잔량, 장애 상태, 환불, 개인정보 삭제, iPhone/Windows 동등 흐름이 부족하다.

## 5~14. 채택 원칙

- 연결 아이콘이 아니라 외부 경로·DNS·IPv6·복구 증거를 보여 준다.
- 개인정보·위치·IP·키를 최소화하고 자동 동의를 금지한다.
- 무료 1GB·무기한 충전·기존 프로필·QR·접근성을 유료 기능 때문에 낮추지 않는다.
- 검열·국가별 성공·법률을 보장하지 않는다.
- 모바일은 연결·복구 중심, PC는 기기·증거·지원 중심으로 역할을 나눈다.
- 자동 검사와 실제 기기·사용자·운영을 섞지 않는다.
- 경쟁사 외형·문구·코드를 복제하지 않는다.
- 도입 금지: 숨은 자동 결제, 강제 계정, 핵심 자료 인질화, 기본 켜진 추적, 검증되지 않은 AI 자동 연결.
