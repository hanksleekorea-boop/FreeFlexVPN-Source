# 비교 서비스 30개 선정

- 후보 66개(A 22, B 22, C 22)
- 선정 30개(A/B/C 각 10), 제외 36개
- 통과선 65점. 그룹별 점수는 목적이 달라 합산 순위를 만들지 않았다.

## A 직접 경쟁

- SVC-001 **Proton VPN** 96점 — 무료 무제한·오픈소스·감사·연결 보호가 직접 비교에 적합 (SRC-001, SRC-039, SRC-040)
- SVC-002 **Mullvad VPN** 94점 — 계정 최소화·고정 월 요금·공개 보안 원칙이 신뢰 기준에 적합 (SRC-002, SRC-039, SRC-040)
- SVC-003 **NordVPN** 91점 — 다중 플랫폼 연결 보호와 복구·부가 보안 기능이 성숙 (SRC-003, SRC-039, SRC-040)
- SVC-004 **Surfshark** 90점 — 무제한 기기와 소비자 중심 연결·부가 안전 흐름 (SRC-004, SRC-039, SRC-040)
- SVC-005 **ExpressVPN** 91점 — 쉬운 시작·다중 플랫폼·연결 설명과 복구 자료 (SRC-005, SRC-039, SRC-040)
- SVC-006 **IVPN** 93점 — 이메일 없는 가입·오픈소스·감사·정직한 한계가 FreeFlexVPN 원칙과 유사 (SRC-006, SRC-039, SRC-040)
- SVC-007 **Windscribe** 85점 — 무료 데이터 한도와 연결·차단 기능이 1GB 권리 모델과 직접 비교 가능 (SRC-007, SRC-039, SRC-040)
- SVC-008 **TunnelBear** 86점 — 2GB 무료 체험·단순한 연결·정기 감사·쉬운 문구 (SRC-008, SRC-039, SRC-040)
- SVC-009 **Private Internet Access** 88점 — 오픈소스·투명성 보고·다중 플랫폼과 구독 운영 (SRC-009, SRC-039, SRC-040)
- SVC-010 **CyberGhost VPN** 84점 — 소비자 기능·지원·투명성 보고가 상용 운영 비교에 유용 (SRC-010, SRC-039, SRC-040)

## B 분야별 선두

- SVC-011 **Tailscale** 94점 — FreeFlexVPN의 기기 수명주기·망 전환·권한·복구 관행을 비교하기 위해 선정 (SRC-011)
- SVC-012 **Cloudflare WARP** 92점 — FreeFlexVPN의 한 번 누르는 연결·다중 플랫폼·망 전환 관행을 비교하기 위해 선정 (SRC-012)
- SVC-013 **Signal** 89점 — FreeFlexVPN의 개인정보 기본값·최소 수집·신뢰 설명 관행을 비교하기 위해 선정 (SRC-013)
- SVC-014 **Tor Browser** 90점 — FreeFlexVPN의 검열 저항·위협 모델·정직한 한계 관행을 비교하기 위해 선정 (SRC-014)
- SVC-015 **Bitwarden** 88점 — FreeFlexVPN의 계정 복구·기기 통제·내보내기·감사 관행을 비교하기 위해 선정 (SRC-015)
- SVC-016 **Atlassian Statuspage** 86점 — FreeFlexVPN의 장애 상태·구독 알림·사고 소통 관행을 비교하기 위해 선정 (SRC-016)
- SVC-017 **Stripe Billing** 90점 — FreeFlexVPN의 구독·청구·변경·수익 운영 관행을 비교하기 위해 선정 (SRC-017)
- SVC-018 **Apple App Store Subscriptions** 88점 — FreeFlexVPN의 모바일 가입·갱신·취소·복원 관행을 비교하기 위해 선정 (SRC-018)
- SVC-019 **Accessibility Insights** 84점 — FreeFlexVPN의 자동·수동 접근성 검증 관행을 비교하기 위해 선정 (SRC-019)
- SVC-020 **GitHub Advanced Security** 87점 — FreeFlexVPN의 비밀값·의존성·코드 위험의 지속 검사 관행을 비교하기 위해 선정 (SRC-020)

## C 인접·대체

- SVC-021 **NextDNS** 90점 — 같은 사용자 목적을 개인화 DNS 보안·추적 차단 흐름으로 대체해 학습 가치가 있음 (SRC-021)
- SVC-022 **AdGuard DNS** 86점 — 같은 사용자 목적을 DNS 기반 광고·추적·악성 도메인 차단 흐름으로 대체해 학습 가치가 있음 (SRC-022)
- SVC-023 **Quad9** 84점 — 같은 사용자 목적을 무료 보안 DNS와 최소 개인정보 흐름으로 대체해 학습 가치가 있음 (SRC-023)
- SVC-024 **Brave** 88점 — 같은 사용자 목적을 브라우저 기본 추적 방어 흐름으로 대체해 학습 가치가 있음 (SRC-024)
- SVC-025 **Firefox** 86점 — 같은 사용자 목적을 브라우저 개인정보 통제와 확장성 흐름으로 대체해 학습 가치가 있음 (SRC-025)
- SVC-026 **DuckDuckGo App** 87점 — 같은 사용자 목적을 검색·브라우저·추적 방어 통합 흐름으로 대체해 학습 가치가 있음 (SRC-026)
- SVC-027 **Psiphon** 90점 — 같은 사용자 목적을 검열 환경 접근과 자동 경로 선택 흐름으로 대체해 학습 가치가 있음 (SRC-027)
- SVC-028 **ZeroTier** 82점 — 같은 사용자 목적을 기기 중심 가상 네트워크 흐름으로 대체해 학습 가치가 있음 (SRC-028)
- SVC-029 **Outline** 88점 — 같은 사용자 목적을 사용자·조직이 관리하는 접근 서버 흐름으로 대체해 학습 가치가 있음 (SRC-029)
- SVC-030 **Opera Free VPN** 76점 — 같은 사용자 목적을 별도 VPN 앱 없이 브라우저 안에서 쓰는 대체 흐름 흐름으로 대체해 학습 가치가 있음 (SRC-030)

## 제외 원칙

종료·중복·공식 근거 부족·65점 미달·FreeFlexVPN 핵심 과업과 낮은 관련성은 강제로 포함하지 않았다. 전체 후보와 제외 이유는 JSON에 있다.
