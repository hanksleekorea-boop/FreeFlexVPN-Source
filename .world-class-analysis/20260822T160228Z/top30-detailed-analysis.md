## 직접 경쟁에서 배울 결과

1. 연결 버튼보다 보호·누출·복구의 증거가 중요하다.
2. 무료 권리, 기기 수, 데이터 한도, 환불을 한 화면에서 비교 가능하게 해야 한다.
3. 킬 스위치와 항상 연결은 해제 경로까지 실제 기기에서 검증해야 한다.
4. 오픈소스 주장은 독립 감사·투명성 보고와 분리해야 한다.

## 분야별 선두에서 배울 결과

- Tailscale: 네트워크 전환·기기 수명주기·기본 거부.
- WARP: 한 번 누르는 시작과 플랫폼 연속성.
- Signal: 개인정보가 선택 기능이 아니라 기본값.
- Tor/Psiphon/Outline: 검열 대응과 실패 가능성의 정직한 고지.
- Statuspage: 고객용 장애 상태와 알림.
- Stripe/Apple: 구독·취소·복원의 실제 상태 모델.
- Accessibility Insights/WCAG: 자동 검사와 사람 검증의 결합.

## 인접 대체에서 배울 결과

DNS·브라우저·자체 관리 접근 도구는 VPN보다 범위가 좁지만 설치 부담·신뢰 이전·사용자 통제에서 다른 해법을 준다. FreeFlexVPN은 이들을 VPN과 동일한 보호로 표현하면 안 된다.
