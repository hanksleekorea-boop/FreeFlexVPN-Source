# 우수 관행 합성 기준

경쟁사 이름이나 외형을 복제하지 않고 사용자 결과로 일반화했다.

## BP-001 보호 상태를 실제 근거로 표시
- 이유: 연결됨과 실제 보호됨을 구분
- 비교 서비스: SVC-001, SVC-006, SVC-012
- 근거: SRC-001, SRC-006, SRC-012, SRC-033
- FreeFlexVPN: partial
- 개선: FreeFlexVPN 정체와 무료 권리를 보존해 보호 상태를 실제 근거로 표시 요구사항으로 재설계
- 검증: 자동 검사 뒤 실제 브라우저·기기·사용자·운영 증거를 별도로 남김
- 부작용: 복잡도·운영 비용 증가 가능
