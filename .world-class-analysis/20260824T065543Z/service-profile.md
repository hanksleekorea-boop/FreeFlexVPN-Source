# FreeFlexVPN 서비스 프로필

실행 ID: 20260824T065543Z · 확인일: 2026-08-24

FreeFlexVPN은 한국어 사용자가 여행·공용망·짧은 업무에서 공식 WireGuard로 필요한 만큼 보호받고, 실제 보호 여부와 무료 권리·한계를 증거와 함께 확인하는 비구독형 VPN/PWA다.

- 핵심 사용자: VPN 초보자, 여행자, 공용망 사용자, 여러 기기를 잇는 사용자
- 구매자: 향후 충전형 데이터를 선택하는 개인 사용자
- 핵심 과업: 시작, 설정 가져오기, 연결, 보호 확인, 사용량 확인, 망 전환, 실패 복구, 기기 해지, 삭제·내보내기, 결제·환불
- 모바일: 보호·복구 중심 반응형 PWA
- PC: 넓은 상태·기기·사용량·QR 작업대
- [확인] Android 15 한 대의 TH→US→TH IPv4 출구, 공개 화면 3종, 일반망 복귀
- [미확인] IPv6·누출·킬 스위치·장시간·iPhone·Windows·실결제·운영·법률
- 수익 구조: 월 무료 1GB + 무기한 충전 방향, 실제 결제는 미검증
