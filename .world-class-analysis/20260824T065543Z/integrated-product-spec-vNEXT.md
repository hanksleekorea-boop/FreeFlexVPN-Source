# FreeFlexVPN 통합 제품기획서 vNEXT

## 1. 제품 한 문장

여행·공용망 사용자가 공식 WireGuard로 안전한 통로를 만들고, 실제 보호 근거·무료 1GB·설정·복구를 쉬운 한국어로 통제하는 서비스.

## 2. 사용자·구매자·비사용자

- 사용자: 해외 체류·공용망·초보 VPN 사용자.
- 구매자: 향후 개인·가족·소규모 팀.
- 비사용자/제외: 불법 우회, 성공 보장이 필요한 고위험 검열 환경, 기업 전사망을 즉시 대체하려는 조직.

## 3. 절대 보존

월 1GB, 무기한 충전, 공식 WireGuard, 기존 프로필, 공개 URL·QR, 접근성, 최소 개인정보, Kakao Connect 격리. 자동 삭제·자동 동의·핵심 자료 유료 인질화 금지.

## 4. 위치와 차별화

대형 VPN의 서버 수를 바로 모방하지 않는다. 실제 증거 등급, 무료 권리 보존, 설정 안전 교체, 쉬운 복구, 운영 정직성을 차별화한다.

## 5. 전체 흐름

유입 → 지원 범위 → 무료 권리 → 앱 설치 → 설정 발급 → 가져오기 → 연결 → 실제 보호 확인 → 반복·망 전환 → 사용량 → 장애·지원 → 취소·삭제·내보내기.

## 6. 모바일·PC 역할

- 모바일: 연결·현재 보호·빠른 복구·사용량.
- PC: 기기·프로필·증거·지원·결제 관리.
- 상태는 같은 ID·시각·등급을 쓰고, 한 플랫폼의 미확인을 다른 플랫폼 완료로 바꾸지 않는다.

## 7. 자료 생명주기

생성 목적·최소 필드·보유 기간·내보내기·폐기·복원·감사 시각을 명시한다. 키·원문 IP·방문 기록은 저장하지 않는다.

## 10. 접근성

WCAG 2.2 AA를 목표로 키보드, 200% 확대, 화면 읽기, 명암, 44px 터치, 오류 연결, 움직임 감소를 자동+사람 검사한다. 인증을 주장하지 않는다.

## 11. 개인정보·보안

최소 수집, 기본 꺼짐, 세션·기기별 권한, 삭제·내보내기·복원, 비밀값 분리, 위협 모델, 외부 검토를 요구한다.

## 12. 가격·무료 권리

무료 1GB와 무기한 충전은 유지한다. 유료화는 총액·자동 갱신·취소·환불·세금·영수증 실제 왕복 전 공개하지 않는다.

## 13. 지원·장애

운영 주체·문의 채널·응답 기준·상태판·긴급 중지·되돌리기 훈련을 둔다.

## 14. 성공 지표와 금지 지표

성공: 실제 보호 확인률, 실패 복구율, 자료 무손실, 환불 완료, 접근성 과업 완료, 장애 알림. 금지: 연결 버튼 클릭만을 보호 성공으로 계산, 가상 사용자를 실제 고객으로 계산, 내부 점수를 시장 1위로 표현.

## 15~16. 출시 통과와 세계 최고 후보 조건

필수 갭 0, 실제 Android/iPhone/Windows, 보조기술, 삭제·복원, 결제·환불, 지원 훈련, 외부 보안 검토, 동일 과업 재비교가 필요하다. 그 전에는 99%·세계 최고를 선언하지 않는다.

## 17. 3단계 범위

1단계: 독립 정상 서비스·실제 보호·자료 통제·지원 기반. 2단계: 선두 동등·개인화·다중 플랫폼. 3단계: 검증된 차별화·제한 파일럿·외부 검토.
