# FreeFlexVPN — 시작하세요

이 프로젝트는 무로그인·기기 중심 VPN 서비스의 웹·PC·모바일 화면과 운영 준비물을 함께 관리하는 개발 원본입니다.

## 지금 읽을 정본

1. 현재 작업 상태와 다음 한 가지 행동: `.project-continuity/STATE.md`
2. 현재 제품 기획: `10_PLAN/CURRENT_SERVICE_PLAN.md`
3. 현재 상세 개발실행계획: `10_PLAN/CURRENT_DEVELOPMENT_EXECUTION_PLAN.md`

## 이 PC에서 다른 Codex 계정으로 이어가기

Codex에서 로그아웃한 뒤 다른 ChatGPT 계정으로 로그인하고, 현재 작업 폴더로 사용 중인
`owner-gateway-v38` 폴더를 그대로 엽니다. 드라이브와 Windows 사용자명은 PC마다 다르므로
고정 절대 경로를 복사하지 말고 `Get-Location`으로 현재 경로를 확인합니다.

`00_START/NEW_CODEX_ACCOUNT_HANDOFF.md`의 첫 메시지를 사용하고 `.project-continuity/runtime/continuity-v520.py bootstrap --project-path . --compact`를 먼저 실행합니다. 출력 HOT JCS와 4 KiB 이하 `CONTEXT.md`만 우선 읽습니다. 로컬 파일과 Git 이력은 같은 PC에 남지만, GitHub·Cloud·Drive 권한과 채팅 기억은 새 계정에 자동 승계되지 않으므로 각각 readback합니다.

## 안전한 개발 시작

- 원격 원본은 공개 `hanksleekorea-boop/FreeFlexVPN-Source`이며 누구나 clone·fork·Issue·Pull Request로 잠금 없이 참여할 수 있습니다.
- 원격 기준 갈래에는 직접 저장 기록을 남기지 않고 새 기능 갈래에서 작업합니다.
- 협업 `LOCK*.json`은 만들지 않으며 Git 상태·STATE·HISTORY로 충돌을 피합니다.
- 기존 Android `ffvpn` 프로필은 삭제·덮어쓰기하지 않습니다.
- 새 PC 준비는 `00_START/NEW_PC_SETUP.md`를 따릅니다.
- 과거 기획·실행계획과 이전 시작 안내는 `90_ARCHIVE/`에 보존되어 있습니다.
