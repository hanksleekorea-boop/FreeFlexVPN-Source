# FreeFlexVPN — 시작하세요

이 프로젝트는 무로그인·기기 중심 VPN 서비스의 웹·PC·모바일 화면과 운영 준비물을 함께 관리하는 개발 원본입니다.

## 지금 읽을 정본

1. 현재 제품 기획: `10_PLAN/CURRENT_SERVICE_PLAN.md`
2. 현재 상세 개발실행계획: `10_PLAN/CURRENT_DEVELOPMENT_EXECUTION_PLAN.md`
3. 현재 작업 상태와 다음 한 가지 행동: `.project-continuity/STATE.md`

## 다음 첫 행동

새 Codex 계정 인계는 `00_START/NEW_CODEX_ACCOUNT_HANDOFF.md`의 단일 프롬프트를 사용합니다. 개발 시작 전에는 반드시 `.project-continuity/STATE.md`와 Git 상태를 읽고, 기존 `ffvpn` 프로필은 삭제·덮어쓰기 없이 재현 방법부터 확인합니다.

## 안전한 개발 시작

- 원격 원본은 공개 `hanksleekorea-boop/FreeFlexVPN-Source`이며 누구나 clone·fork·Issue·Pull Request로 잠금 없이 참여할 수 있습니다.
- `main`에는 직접 저장 기록을 남기지 않고 새 기능 갈래에서 작업합니다.
- 새 PC 준비는 `00_START/NEW_PC_SETUP.md`를 따릅니다.
- 이 PC에서 다른 Codex 계정으로 이어갈 때는 `00_START/NEW_CODEX_ACCOUNT_HANDOFF.md`를 사용합니다.
- 과거 기획·실행계획과 이전 시작 안내는 `90_ARCHIVE/`에 보존되어 있습니다. 삭제한 파일은 없습니다.
