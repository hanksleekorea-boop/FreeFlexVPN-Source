## 1. 제품/일 한 문단

FreeFlexVPN은 가끔 VPN이 필요한 라이트 사용자가 매달 1GB를 무료로 받고, 더 필요할 때만 약정이나
자동결제 없이 용량을 충전해 쓰도록 설계한 서비스다. 웹앱은 계정·잔액·추천·WireGuard 구성을 관리하고,
실제 터널은 운영체제의 공식 WireGuard 앱이 실행한다. 공개된 것은 로그인 없이 열리는 **UI 앱 셸 v2.3**이며,
실제 VPN 서버, 실제 결제, 실제 기기 터널과 독립 사용자 성공은 아직 없다. 현행 개발 후보는
`v2.15-r2`이고, 로컬에는 원가 모델·PWA·제어 API·쿼터·피어 발급·Telegram·GCP 배포 전 도구와 검사가 있다.

공개 앱: https://hanksleekorea-boop.github.io/FreeFlexVPN/app.html

## 6. 이 프로젝트가 비싸게 배운 것

1. **한 공급자만 보고 한국 원가를 일본의 74배라고 잘못 말했다.** 53개국 전수 조사 뒤 Vultr 서울을 반영해
   22배로 정정했다. 그래서 국가는 그 지역의 최저가 옵션을 비교하고 공급자·분모·분자를 함께 적는다.
2. **EUR 기본료와 USD 지역 추가금을 같은 통화처럼 더해 20개국 합계가 820원 어긋났다.** 그래서 모든
   혼합 통화는 원화 환산 뒤 합산한다.
3. **하드코딩 금지 검사가 자기 리터럴에 걸려 실패했다.** 그래서 자기 소스를 검사하는 바늘 문자열은
   조립하고 검사 범위를 제한한다.
4. **배포 채널이 없는데 문서만 일곱 번 늘렸다.** 그래서 문서 추가는 진척이 아니며, 차단 경로는 보고 상단에 둔다.
5. **Word 자동 목차가 LibreOffice PDF에서 빈 페이지가 됐다.** 그래서 정적 목차와 실제 PDF 시각 검사를 사용한다.
6. **‘무제한’ 호스팅의 속도 제한을 놓칠 뻔했다.** 그래서 포트 속도·fair-use·추가 대역폭 가격을 함께 계산한다.

전문은 `10_STATE/LESSONS.md`에 있다. 상상한 교훈을 추가하지 않는다.

## 7. 사용자와 일하는 방식

- 기본 언어는 한국어다. 쉬운 요약을 먼저 쓰고 수치·근거를 뒤에 둔다.
- 원본과 더러운 작업 트리를 보존하고, 버전이 붙은 후보와 되돌리기 경로를 사용한다.
- 보고에는 기준선 대비 변화, 검사 수, 병목·해소, 다음 안전 행동, 현재 공개 앱 링크를 포함한다.
- 공개 앱·브라우저·로컬 증거를 서버·실기기·파일럿 증거로 부풀리지 않는다.
- 새 증거가 없으면 진행률 숫자를 올리지 않는다.
- 연속 신호 `0`, `j`, `ㅋ`, `ㅇ`은 가장 높은 비차단·사용자 독립 작업을 실행하라는 뜻이다.
  이 신호는 결제·삭제·권한 변경 등 승인을 넓히지 않는다.
- 명시 승인이 계속 필요한 것: 결제, 계정·권한, 비밀값, 개인정보, 데이터 삭제,
  제3자 연락, 실사용자 모집, 실기기 조작, 비용 발생 자원.

## 9. 첫 턴에 이것을 보고하라

먼저 zip을 별도 폴더에 풀고 프로젝트 루트에서 아래 명령을 **실제로 실행**한다.

1. zip 안 실파일 수와 `MANIFEST.md`의 파일 수를 대조한다. 생성 이관본의 기대값은
   **zip 실파일 279개 = MANIFEST 추적 파일 278개 + MANIFEST 자기 자신 1개**다. 그 다음:

   ```powershell
   python -X utf8 70_TOOLS/make_manifest.py --check
   ```

   기대: `MANIFEST 왕복 대조 PASS`와 모든 해시 일치.

2. 환경에서 되는 것·안 되는 것을 표로 쓰고 §4 선언 문구를 포함한다.

3. 경로와 계약 모델을 확인한다.

   ```powershell
   python -X utf8 70_TOOLS/fkvpaths.py
   python -X utf8 20_SRC/cost_model.py
   ```

   기대: 루트 표식 4개 확인, 단위 원가 2.94원/GB, safe 588,257원, 무료 1개월 46,931원.

4. 전체 회귀를 실행한다.

   ```powershell
   python -X utf8 70_TOOLS/run_all_tests.py
   ```

   생성 환경 기대 기준: **41/41 파일, 454/454 검사, 실패 0**. 다르면 파일·항목·원인을 그대로 적는다.

5. 공개 앱 검사를 별도로 확인한다.

