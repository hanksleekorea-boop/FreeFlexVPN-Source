## 오류·병목·위험

### ⚠ 실제 Android 검사 필요 — 보호 범위 완결 검사

Android에서 설정 가져오기·VPN 연결 요청·터널·IPv4·DNS·꺼짐 뒤 재연결의 과거 증거와 차단 모드 동작 증거가 있다. 그러나 최신 재현에서는 VPN을 켜면 일반 웹이 표시되지 않고, VPN을 끄면 같은 웹이 정상 표시된다. IPv6·외부 경로 일치·차단 뒤 자동 복구는 진행하지 않고, 실제 데이터 경로 복구를 최우선으로 한다.

- 오류: VPN 켬 상태에서는 일반 웹이 표시되지 않고, VPN 끔 상태에서는 동일 웹이 표시된다. VPN·차단 모드는 현재 해제돼 일반 인터넷 복구를 확인했다. 원인은 아직 분리하지 않았고, 외부 IP 값은 개인정보 원칙에 따라 기록하지 않았다.
- 병목: P1 공개 이관은 완료했다. 현재 최우선 병목은 Android 실제 VPN 데이터 경로다. 서버 실행·UDP 방화벽·대상 태그·외부 통신·IP 전달·NAT·전달 규칙·최근 악수는 읽기 전용으로 확인됐으므로, 현재 A56 프로필 또는 클라이언트 데이터 경로를 우선 분리해야 한다.
- 풀리는 조건: 새 검증용 Android 프로필을 별도 발급·가져오기한 뒤, A56에서 VPN 켬 상태의 일반 웹 표시를 다시 확인한다. 기존 프로필은 삭제하지 않고 보존한다.
- 사용자 결정 필요: 없음 — 현재 VPN은 끈 상태로 복구했으며, 다음 원인 분리 검사는 읽기 전용으로 진행할 수 있다.

## 2026-08-11 A56 데이터 경로 분리 결과

- 새 검증 터널 `ffvpn-a56v`는 실제 Android에서 일반 웹·DNS/도달성·서버 최근 악수까지 통과했다. 터널을 끈 뒤의 일반 인터넷 복귀도 확인했고, 두 저장 터널은 모두 꺼진 상태다.
