# 무잠금 프로젝트 운영 정책

- 적용일: 2026-08-13
- 근거: 사용자의 명시 지시 — 현재 모든 프로젝트 협업 잠금을 해제하고 향후에도 잠금을 만들지 않는다.
- 적용 범위: 이 FreeFlexVPN 작업 폴더의 `.project-continuity/LOCK*.json` 협업 잠금.
- 현재 상태: 기존 협업 잠금 파일 19개 제거, 남은 협업 잠금 0개, Git `*.lock` 0개 확인.
- 향후 운영: 작업 시작·종료 때 협업 잠금 파일을 생성하지 않는다. 충돌 방지는 Git 상태(`git status`), `STATE.md`, `HISTORY.md`, 변경 경로 대조로 수행한다. 상위 v10.6 정책과 진입 도구도 협업 잠금 파일을 생성하지 않는다.
- 감시: `.gitignore`에서 협업 잠금 숨김 규칙을 제거했으므로 잘못 생성된 잠금은 `git status`에 즉시 드러난다.
- 제외: Chromium/LevelDB 등 외부 프로그램이 자체 데이터 무결성을 위해 실행 중 자동 생성하는 `LOCK` 파일은 프로젝트 협업 잠금이 아니며, 강제 삭제하면 프로필 손상이 생길 수 있어 이 정책의 제거 대상이 아니다.
- 한계: 운영체제·Git·브라우저 등 외부 도구가 내부적으로 만드는 순간 잠금까지 영구 금지한다고 보장하지 않는다.
