## 0. v4의 단일 결정

앞서 정한 제품·UX 100개를 FreeFlexVPN의 최상위 제품 백로그로 승격한다. 보안·개인정보·전면 장애의 긴급 수정과 신규기능에 꼭 필요한 기반 수정 외에는, 모든 기존 대기 기능·장식 개선·마케팅·수익화 실험을 100개 뒤로 보낸다.

사용자가 느끼는 v4의 변화는 “기능이 많아졌다”가 아니라 다음 네 문장으로 설명한다.

1. 지금 실제로 보호되는지 정직하게 알 수 있다.
2. 문제가 생겨도 1분 안에 다음 행동을 찾을 수 있다.
3. Android·iPhone·PC와 여러 기기를 안전하게 이어서 쓸 수 있다.
4. 서버·사용량·장애·개인정보의 근거와 한계를 숨기지 않는다.

## 1. 현재 사실과 출시 출발점

- 현재 공개 서비스에는 반응형 UI, Android 설정 안내, QR, 기본 대시보드가 있다.
- `connection_check.py`에는 다섯 제품 상태(`setup_needed`, `disconnected`, `checking`, `limited`, `protected`)의 fail-closed 판정이 있다. 필요한 근거가 모두 참일 때만 `protected`다.
- A56에서는 일반 인터넷·DNS를 확인했지만 활성 WireGuard 세션·터널 경로는 확인하지 못했다.
- iPhone 실기기 검증과 실제 운영 서버 자료 연결은 미완료다.
- 1,000명 분석은 실제 고객 설문이 아니라 가상 사용자 가설이다.

따라서 v4는 “연결 성공”을 마케팅하기 전에 “실제 확인/확인 중/확인 불가/실패”를 구분하는 기능부터 만든다.

## 4. 모바일·PC 서비스 경험

### 4.1 모바일: 한눈에 확인하고 바로 복구

첫 화면은 보호 상태, 확인 근거, 마지막 확인 시각, 다음 한 행동으로 시작한다. QR 가져오기, 네트워크 전환, 기기 해지, 공용망 경고는 깊은 도움말이 아니라 해당 순간의 화면에서 바로 찾을 수 있어야 한다.

### 4.2 PC: 기기·상태·통계·QR을 함께 보는 작업대

1024px 이상에서는 기기 목록, 보호 상태, 사용량/이력, QR 핸드오프를 다단으로 보인다. 키보드만으로 주요 기능을 실행하고 포커스를 확인할 수 있어야 한다. 1024px 미만의 기존 모바일 흐름은 회귀 검사로 보호한다.

### 4.3 신뢰센터: 실제 자료와 모르는 것을 함께 공개

서버·장애·정비·사용량·성공률은 출처와 갱신 시각이 있을 때만 표시한다. 자료가 없거나 오래되면 `알 수 없음`, `마지막 확인`, `준비 중` 중 맞는 표현을 쓴다. 개인정보·보안 이력·약관 변경·지역 안내도 같은 원칙을 따른다.

## 5. 제품 문구 계약

| 상황 | 허용 표현 | 금지 표현 |
|---|---|---|
| 실제 근거 전부 확인 | 보호 확인됨 + 확인 시각·근거 | 완전 안전 보장 |
| 연결됐지만 보호 근거 부족 | 연결됨, 보호 상태 확인 불가 | 보호됨 |
| 검사 진행 | 확인 중 + 취소/재시도 | 거의 안전함 |
| 운영 자료 없음 | 알 수 없음/준비 중 | 정상/쾌적/실시간 |
| iPhone 실기기 전 | 안내 제공, 실기기 확인 전 | iPhone 검증 완료 |
| 가상 분석 | 사용성 가설 | 고객 1,000명 조사 결과 |

## 6. 신규기능 우선 운영 규칙

1. F0-1부터 F6-2까지 순서대로 개발한다.
2. 기존 기능의 회귀 수정은 현재 신규기능 묶음의 완료를 위해 필요할 때만 같이 처리한다.
3. 마케팅 카피, 추천 보상, 추가 과금, 장식적 홈 개편은 F6-2 뒤다.
4. 긴급 보안·개인정보·전면 장애가 끼어들면 중단 이유와 복귀 지점을 기록한다.
5. 실제 데이터 계약이 없는 기능은 가짜 수치로 완성하지 않고 빈 상태와 연동 대기를 구현한다.
6. 기능을 만들었어도 홈·메뉴·오류·단축키 중 실제 진입 경로가 없으면 미완료다.

- P0의 실제/미확인 오표시 0건

- 신규기능 실제 도달 경로 100%

### 7.2 제품 학습 지표

- 첫 설정 완료율, 복구 완료율, 연결 확인 소요 시간
- QR 오류 유형과 도움말 도달률
- 서버 선택·추천 끄기·기기 해지의 성공률
- 접근성 핵심 흐름 완료율

실제 사용자 동의 전에는 제품 학습 지표를 외부로 보내지 않는다. 기기 안 측정 또는 동의형 측정만 사용한다.

## 9. 범위 절단과 정지 조건

- 절단 금지: 상태 정직성, 비밀값 가림, 데이터 삭제권, 긴급 해지 확인, 접근성 기본 도달성.
- 먼저 자를 것: 장식 애니메이션, 부가 통계, 자동 추천의 고급 설명, 마케팅 문구.
- 정지 조건: 모바일 회귀, 보호 오표시, 비밀값 노출, 실제 자료 없는 확정 표시, 기기 해지 오작동.
- 각 작업 묶음 착수 전 로직:문자열 바이트를 1:1로 견적하고 완료 후 압축 실측을 남긴다.

## 10. 권한 경계

이 기획서는 파일 구현, Git 커밋/push, 공개 배포, 비용 발생, 실제 기기·VPN 설정 변경을 승인하지 않는다. 개발은 파일 락과 현재 세션 승인을 따르며, 공개 검증은 별도 승인 뒤 수행한다.
