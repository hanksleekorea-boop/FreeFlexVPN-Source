## 0. 이번 업그레이드의 의미

FreeFlexVPN v1은 월 1GB 무료, 충전분 무기한, 자동결제 없음이라는 가격 약속을 세웠다. v2는 이 약속을 유지하면서 제품 중심을 “서버를 고르는 VPN”에서 **“VPN이 필요한 순간을 가장 짧고 정직하게 해결하는 서비스”**로 바꾼다.

이번 기획서가 새로 확정하는 다섯 가지는 다음과 같다.

1. 무료 사용자를 포함한 모든 사용자에게 VPN 안전 기본기를 제공한다.
2. 서버 국가보다 사용 목적과 상황을 먼저 보여 준다.
3. 월 1GB 무료, 무기한 데이터 지갑, 일회성 충전을 하나의 일관된 경험으로 만든다.
4. 만족한 사용자가 친구를 데려오면 양쪽에 데이터로 보상하는 추천 루프를 만든다.
5. 헤비 사용자에게는 종량제가 불리해지는 순간을 숨기지 않고 월정액 대안을 안내한다.

이 문서는 제품 방향을 확정하지만 실제 VPN 서버, 결제, 실기기, 파일럿 성공을 만들어 내지는 않는다. 구현과 검증은 §13의 릴리스 순서와 완료 증거로 별도 판정한다.

## 1. 제품 비전과 포지셔닝

### 1.1 비전

VPN을 매일 쓰는 전문 도구가 아니라 우산처럼 만든다. 평소에는 잊고 지내다가 공용 Wi-Fi, 여행, 지역별 공개 웹 확인, 일시적인 연결 문제처럼 필요한 순간에 꺼내 쓰고 다시 넣어 두는 서비스다.

### 1.2 핵심 포지셔닝

**“VPN은 가끔 필요한데 매달 돈 내기는 싫은 사람을 위한 가장 마음 편한 선택.”**

경쟁의 기준은 무료 데이터 양 하나가 아니다. Proton VPN은 무료 무제한, Windscribe는 이메일 확인 시 월 10GB, TunnelBear는 무료 2GB를 공식 제공한다. FreeFlexVPN은 이들과 무료 용량으로 정면 승부하지 않는다. 대신 다음 네 가지를 한 묶음으로 제공한다.

- 매월 1GB 무료
- 필요한 만큼만 한 번 충전
- 구매·추천 데이터 무기한
- 자동결제·해지 절차 없음

### 1.3 브랜드 약속

| 약속 | 사용자에게 보이는 행동 | 금지되는 행동 |
|---|---|---|
| 필요할 때만 | 첫 화면에서 바로 연결 가능 | 출석·연속 접속으로 불필요한 사용 유도 |
| 산 것은 사라지지 않음 | 무료·추천·구매 잔액을 분리 표시 | 충전 데이터의 조용한 만료 |
| 안전은 기본 | 무료에도 킬 스위치·DNS/IPv6 보호 | 안전 기능을 유료벽 뒤에 배치 |
| 정직한 가격 | 자동결제 없음, 헤비 사용 시 정액제 권고 | 갱신가·숨은 수수료·위장 할인 |
| 말보다 확인 | 연결 상태·출구 IP·최근 확인 시각 표시 | 버튼 색상만으로 보호 완료 주장 |

## 2. 목표 사용자와 제외 사용자

### 2.1 핵심 사용자

**상황형 라이트 사용자**는 VPN을 매일 켜지 않는다. 월 사용량보다 “이번 순간을 안전하고 빠르게 끝낼 수 있는가”를 중요하게 생각한다.

- 여행 중 공항·호텔·카페 Wi-Fi를 잠깐 쓰는 사람
- 예약, 메일, 지도, 금융·행정 웹 과업을 짧게 처리하는 사람
- 다른 국가에서 보이는 공개 웹 화면을 업무·조사 목적으로 확인하는 사람
- 통신사나 인터넷 경로 문제를 다른 경로로 잠깐 시험하는 사람
- 구독과 해지를 관리하고 싶지 않은 사람

### 2.2 보조 사용자

- 월정액 VPN을 사기 전에 안전한 무료 기본 기능을 체험하려는 사람
- 여행 전 데이터를 미리 조금 충전해 두고 필요할 때만 쓰려는 사람
- 가족·친구에게 복잡하지 않은 VPN을 추천하고 싶은 기존 만족 사용자

### 2.3 의도적으로 최적화하지 않는 사용자

- 매달 50GB 이상을 지속적으로 쓰는 헤비 사용자
- 고화질 스트리밍·대용량 다운로드·P2P를 주목적으로 쓰는 사용자
- 특정 스트리밍 서비스 해제나 레지덴셜 IP를 요구하는 사용자
- 위장 프로토콜이 필요한 고강도 검열 우회 사용자

이 사용자를 차단하거나 폄하하지 않는다. 다만 FreeFlexVPN보다 월정액 또는 전문 서비스가 유리할 수 있음을 먼저 안내한다.

## 3. 사용자가 VPN을 켜는 핵심 순간

### 3.1 순간 1 — 공용 Wi-Fi 보호

- 진입 문구: “공항·호텔·카페 Wi-Fi인가요?”
- 기본 행동: 가장 가까운 정상 서버 자동 선택
- 완료 화면: 터널 확인, 출구 IP, DNS 보호 상태, 연결 시각
- 한계 고지: VPN은 피싱·악성 앱·계정 탈취를 모두 막는 보안 제품이 아니다.

### 3.2 순간 2 — 여행 중 잠깐 사용

- 진입 문구: “예약·지도·메일을 잠깐 확인할까요?”
- 기본 행동: 빠른 서버, 저잔액 사전 경고, 사용 후 세션 요약
- 데이터 안내: 고정된 시간 환산 대신 사용자의 최근 실제 세션을 기준으로 예상

### 3.3 순간 3 — 다른 국가의 공개 웹 확인

- 진입 문구: “어느 지역에서 보이는 화면이 필요하세요?”
- 기본 행동: 실제 제공 중인 국가만 카탈로그에서 노출
- 한계 고지: 데이터센터 IP이며 스트리밍·쇼핑·금융 서비스의 접속 성공은 보장하지 않음

### 3.4 순간 4 — 연결 문제 해결

- 진입 문구: “현재 사이트가 열리지 않나요?”
- 기본 행동: 가까운 다른 경로로 연결 시험, 실패하면 대체 노드 제안
- 한계 고지: VPN 자체가 차단된 네트워크나 캡티브 포털에서는 먼저 Wi-Fi 로그인이 필요할 수 있음

### 3.5 프라이버시 원칙

사용 목적 선택은 선택사항이며 기본적으로 기기 안에서만 처리한다. 방문 사이트, DNS 질의 원문, 콘텐츠, 목적 선택 이력을 추천·광고에 사용하지 않는다.

## 4. v2 서비스 구조

### 4.1 4개 핵심 영역

| 영역 | 사용자 질문 | 핵심 기능 |
|---|---|---|
| 홈 | 지금 왜 VPN이 필요한가 | 순간 카드, 바로 연결, 실제 보호 확인 |
| 데이터 | 얼마나 남았고 무엇이 먼저 차감되는가 | 무료·추천·구매 지갑, 세션 요약, 충전 |
| 함께 쓰기 | 친구와 어떻게 혜택을 나누는가 | 링크·QR·메신저 공유, 보상 상태 |
| 내 정보 | 내 기기와 안전 상태는 어떤가 | 기기 폐기, 안전 센터, 정책·삭제 |

### 4.2 12개 화면

1. **시작** — 한 문장 가치, 월 1GB 무료, 충전분 무기한, 자동결제 없음
2. **동의** — 최소 수집, 로그·삭제·국외처리의 쉬운 설명
3. **설정** — 공식 WireGuard 앱 설치와 개인키 경계
4. **순간 홈** — 목적 카드 4개와 바로 연결
5. **보호 상태** — 핸드셰이크·출구 IP·DNS·최근 확인 시각
6. **국가 선택** — 실제 공급 가능한 서버만 표시
7. **데이터 지갑** — 무료·추천·구매 잔액 분리
8. **용량 충전** — 3GB·10GB 중심, 30GB 더 보기
9. **친구와 나누기** — 양쪽 보상, 공유, 진행 상태
10. **기기 관리** — 활성 키 2개, 이름 변경, 즉시 폐기
11. **사용 기록** — 세션별 사용량, 월간 합계, 잔액 변화
12. **안전·계정** — 장애 상태, 정책, 데이터 내보내기·삭제

### 4.3 하단 내비게이션

- 홈
- 데이터
- 함께 쓰기
- 내 정보

연결 버튼은 홈의 가장 중요한 행동으로 유지한다. 결제와 추천은 연결보다 시각적으로 앞서지 않는다.

## 5. VPN 안전 기본기

### 5.1 전 사용자 무료 제공

- WireGuard 암호화 터널
- 킬 스위치 또는 OS별 동등한 트래픽 차단
- DNS 누수 방지
- IPv6 누수 방지 또는 명시적 안전 차단
- Wi-Fi↔모바일 전환·절전·재시작 후 자동 재연결
- 실제 터널 상태, 출구 IP, 마지막 핸드셰이크 확인
- 서버 장애 시 대체 노드 안내
- 캡티브 포털 감지와 로그인 후 재연결 안내

### 5.2 연결 상태 언어

| 상태 | 표시 | 판정 근거 |
|---|---|---|
| 준비 안 됨 | “설정이 필요합니다” | 유효한 프로필·키 없음 |
| 연결 중 | “보호를 확인하고 있습니다” | 터널 시작, 외부 확인 미완료 |
| 보호됨 | “VPN 보호 확인됨” | 최근 핸드셰이크 + 할당 출구 IP 확인 |
| 제한됨 | “연결됐지만 일부 확인 불가” | 터널은 있으나 DNS·상태 확인 실패 |
| 끊김 | “현재 VPN 보호 안 됨” | 터널·핸드셰이크 없음 |

버튼을 눌렀거나 설정 파일을 발급했다는 사실만으로 “보호됨”을 표시하지 않는다.

### 5.3 PWA와 네이티브 경계

1차 공개는 기존 결정대로 PWA와 공식 WireGuard 앱을 사용한다. 브라우저는 OS의 VPN 터널 상태를 직접 제어하거나 완전히 관찰할 수 없으므로, PWA의 연결 확인은 FreeFlexVPN의 공개 확인 엔드포인트에서 출구 IP와 세션 상태를 확인한 결과로 제한한다.

네이티브 앱은 다음 조건이 모두 생길 때 별도 릴리스로 승격한다.

- 실제 사용자들이 외부 WireGuard 앱 이동을 핵심 이탈 원인으로 반복 보고
- 실기기 파일럿에서 첫 연결 성공률과 재연결 결함이 측정됨
- 앱스토어 계정·심사·개인정보·업데이트 운영비를 감당할 근거 확보

네이티브 전환 전까지 PWA에서 직접 VPN을 켰다고 가장하지 않는다.

## 6. 데이터 지갑과 과금

### 6.1 잔액 세 종류

| 지갑 | 지급 | 유효기간 | 차감 순서 |
|---|---|---|---|
| 무료 데이터 | 매월 1GB | 해당 월 말 | 1순위 |
| 함께 받은 데이터 | 추천 자격 충족 | 무기한 | 2순위 |
| 구매 데이터 | 일회성 충전 | 무기한 | 3순위 |

무료 잔액이 매월 갱신돼도 추천·구매 잔액은 줄거나 사라지지 않는다. 원장 저장 실패 시 차단 상태를 임의로 풀지 않고 원본을 보존하며 정직하게 알린다.

### 6.2 가격팩 v2

| 노출 | 팩 | 현재 설계가 | 역할 | 상태 |
|---|---:|---:|---|---|
| 기본 | 3GB | 1,500원 | 첫 소액 충전 | 지불의사 미검증 |
| 기본 | 10GB | 3,900원 | 대표 라이트 팩 | 지불의사 미검증 |
| 더 보기 | 30GB | 8,900원 | 여행·업무 집중 사용 | 지불의사 미검증 |
| 숨김 | 100GB·300GB | 기존 설계안 보존 | 헤비 사용자 영역 | 파일럿 전 기본 노출 중단 |

결제 전에는 선택 용량, 최종 금액, 자동결제 없음, 만료 없음, 환불 조건을 한 화면에서 확인한다. 실제 결제 사업자와 정책이 연결되기 전에는 결제 버튼을 시뮬레이션으로 유지한다.

### 6.3 헤비 사용자 보호

최근 사용량으로 월 50GB 초과가 예상되면 “FreeFlexVPN 종량제보다 월정액 서비스가 유리할 수 있습니다”를 가격표보다 먼저 보여 준다. 사용자가 그래도 일회성 데이터를 원하는 경우에만 더 큰 팩을 열어 준다.

## 7. 친구 추천과 상호 보상

### 7.1 추천 약속

**“친구가 실제로 써 보면 둘 다 500MB.”**

500MB와 월 상한은 v2 파일럿의 운영값이며 영구 가격 계약은 아니다. 변경 시 기존 확정 보상은 소급 축소하지 않는다.

### 7.2 자격과 지급

| 단계 | 규칙 |
|---|---|
| 공유 | 연락처 업로드 없이 링크·QR·운영체제 공유 시트 사용 |
| 귀속 | 무작위 추천 토큰을 신규 계정에 한 번만 귀속 |
| 자격 | 피추천인이 첫 실제 터널에 성공하고 누적 100MB 사용 |
| 지급 | 추천인과 피추천인에게 각각 500MB `earned` 잔액 지급 |
| 상한 | 추천인 기준 월 5건 확정까지 파일럿 |
| 상태 | 대기·자격 충족·확정·지급·보류 사유를 양쪽에 표시 |

현재 모델의 단위 원가 2.94원/GB를 적용하면 양쪽이 500MB를 모두 사용할 때 추천 1건의 순수 트래픽 원가는 약 2.94원이다. 이는 서버 고정비, 공급자 증설, 남용, 운영, 결제 비용을 제외한 모델 계산이며 실제 원가가 아니다.

### 7.3 부정사용 방어

- 추천 토큰 원문 대신 해시 저장
- 자기 추천, 순환 추천, 동일 계정·동일 키 중복 지급 차단
- 한 자격 이벤트당 멱등 키 한 개
- 짧은 시간의 대량 계정·대량 자격은 지급 전 보류
- 이미 선의로 사용한 데이터는 사후 회수해 음수 잔액을 만들지 않음
- 실제 남용이 확인되기 전에는 전화번호·연락처 수집을 추가하지 않음

### 7.4 추천 제안 시점

가입 직후에는 추천을 요구하지 않는다. 첫 보호 성공 후 세션 요약, 또는 두 번째 성공 세션 뒤에 한 번 제안한다. 추천 배너를 닫으면 반복 노출을 제한한다.

## 8. 전체 사용자 여정

### 8.1 첫 사용

1. 가치 약속 확인
2. 최소 정보·개인키 경계 동의
3. 공식 WireGuard 설정
4. 필요한 순간 선택 또는 바로 연결
5. 연결 후 실제 보호 확인
6. 첫 세션 사용량과 남은 무료 데이터 확인

### 8.2 반복 사용

1. 홈에서 마지막 정상 서버와 현재 잔액 확인
2. 한 번의 행동으로 연결 경로 시작
3. 연결 중에는 필요한 상태만 표시
4. 종료 후 이번 세션과 잔액 변화 확인
5. 잔액이 충분하면 결제·추천 메시지를 숨김

### 8.3 잔액 부족

1. 50%, 20%, 100MB 잔여 시점에 조용한 알림
2. 현재 사용 속도에 따른 예상 부족 가능성 표시
3. 3GB·10GB 선택
4. 일회 결제·무기한·자동결제 없음 재확인
5. 결제 성공 후 원장 반영 확인 뒤 차단 해제

### 8.4 만족 후 추천

1. 실제 보호 성공과 세션 완료
2. “친구와 500MB 나누기” 제안
3. 링크·QR·메신저 공유
4. 친구의 자격 진행 상태 확인
5. 양쪽 지급과 지갑 반영

## 9. 흥미를 잃지 않게 하는 방법

FreeFlexVPN의 참여 목표는 체류시간이 아니다. 사용자가 다음 필요 순간에도 믿고 돌아오는 **준비된 신뢰**다.

### 사용할 장치

- 첫 성공까지 단계 수와 남은 한 단계 표시
- 여행 전 “VPN 준비 완료” 체크
- 세션 종료 후 실제 사용량과 보호 결과
- 무기한 잔액이 보존되고 있다는 조용한 확인
- 친구와 나눈 데이터의 실제 진행 상태
- 오류가 났을 때 원인과 다음 행동을 쉬운 말로 제시

### 사용하지 않을 장치

- 매일 출석 보상
- 의미 없는 레벨·배지·연속 사용
- 불필요한 푸시 알림
- 잔액 만료 공포
- 가짜 카운트다운 할인
- 결제 버튼을 연결 버튼보다 크게 만드는 화면

## 10. 개인정보와 신뢰 설계

### 10.1 수집 최소화

- 계정 식별은 HMAC 기반 가명 ID
- WireGuard 개인키는 사용자 기기 밖으로 전송하지 않음
- 추천은 연락처가 아니라 무작위 토큰
- 방문 사이트·콘텐츠·DNS 질의 원문은 수집하지 않음
- 쿼터에 필요한 피어별 송수신 누적량만 사용

### 10.2 사용자 권리

- 수집 항목·목적·보존기간을 앱에서 확인
- 활성 기기 키 즉시 폐기
- 계정·피어·추천 토큰 삭제 요청
- 잔액·보상·결제 내역 내보내기
- 장애·저장 실패·검증 실패를 숨기지 않는 고지

### 10.3 금지 주장

- 법률·운영 설정과 독립 검증 전 “완전한 노로그” 주장 금지
- 특정 서비스·스트리밍 우회 보장 금지
- 실제 측정 전 “가장 빠른 서버” 단정 금지
- PWA 버튼 상태만으로 “완벽히 보호됨” 주장 금지

## 11. 성공 지표

### 11.1 북극성 지표

**월간 성공 보호 순간 수**: 사용자가 실제 터널을 확인하고 의도한 짧은 과업을 끝낸 세션 수.

앱 체류시간과 총 트래픽은 북극성 지표가 아니다.

### 11.2 핵심 지표

| 구간 | 지표 | 초기 판정 기준 |
|---|---|---|
| 활성화 | 설치→첫 실제 보호 성공률 | 기존 T10: 제3자 5명 중 4명 이상 문의 없이 성공 |
| 속도 | 반복 사용자의 보호 확인 시간 | 파일럿에서 OS별 중앙값 측정 후 목표 고정 |
| 안전 | DNS·IPv6·킬 스위치·재연결 | 목표 OS 전건 통과 전 출시 완료 금지 |
| 적합성 | 월 1GB 안에서 의도한 과업을 끝낸 비율 | 4~6주 파일럿으로 측정, 사전 수치 주장 금지 |
| 결제 | 잔액 부족→충전 완료·재사용 | 실제 PG 연결 후 측정 |
| 추천 | 공유→자격 추천 전환·30일 재사용 | 파일럿 코호트로 측정 |
| 신뢰 | 잔액 불일치·오인 결제·환불·삭제 실패 | 중대 불일치 0을 관문으로 사용 |

### 11.3 가드레일

- 개인정보·개인키 유출 0
- 잔액 원장 음수·중복 지급 0
- 실제 보호 안 됐는데 보호됨 표시 0
- 동의 없는 연락처 접근 0
- 추천 부정 지급률과 호스터 abuse 신고를 별도 계측

## 16. 출시 메시지

### 대표 문장

**VPN이 가끔 필요하다면, 매달 내지 마세요.**  
매월 1GB는 무료로 쓰고, 더 필요할 때만 충전하세요. 산 데이터와 친구에게 받은 데이터는 사라지지 않으며 자동결제도 없습니다.

### 보조 문장

- 공용 Wi-Fi부터 여행 중 잠깐의 웹 확인까지, 필요한 순간을 골라 바로 시작합니다.
- 연결 버튼이 아니라 실제 터널과 출구 IP를 확인해 보호 상태를 알려 줍니다.
- 친구가 실제로 써 보면 둘 다 500MB를 받습니다.
- 많이 쓸수록 불리해진다면 월정액이 낫다고 먼저 알려 드립니다.

### 외부 공개 전 금지 문장

- “가장 안전한 VPN”
- “가장 빠른 VPN”
- “모든 스트리밍 완벽 해제”
- “완전한 노로그”
- “대부분의 사용자에게 최고의 VPN”

실기기·파일럿·독립 검증이 쌓이면 근거가 있는 범위에서만 문장을 강화한다.
