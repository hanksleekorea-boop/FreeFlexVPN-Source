## 제품 한 줄

가끔 VPN이 필요한 순간, 구독 없이 바로 보호받고 필요한 데이터만 평생 보관해 쓰는 라이트 VPN.

## 유지된 계약

- FreeFlexVPN
- 월 1GB 무료
- 구매 데이터 무기한
- 자동결제 없음
- 활성 기기 2대
- 한국 exit 노드 미운영
- 스트리밍·레지덴셜 IP·고강도 검열 우회 미보장

## v2 신설 계약

- 무료에도 킬 스위치·DNS/IPv6 보호·재연결·실제 보호 확인
- 공용 Wi-Fi·여행·지역 웹·연결 문제의 순간 중심 홈
- 무료→추천→구매 순서의 3잔액 데이터 지갑
- 친구가 첫 실제 터널과 누적 100MB를 달성하면 양쪽 500MB, 추천인 월 5건 파일럿
- 3GB·10GB 기본, 30GB 더 보기, 100GB·300GB 기본 숨김
- PWA + 공식 WireGuard를 1차로 유지하고 네이티브는 실측 게이트 후 결정

## 현재 증거 경계

- 공개 UI v1.1: 있음
- 로컬 계정·쿼터·피어·Telegram·exit-node 후보: 있음
- 실제 VPN 서버: 0대
- 실제 터널·기기 안전 검증: 0건
- 실제 결제·추천·파일럿: 0건

v2 기준선은 3/12 = 25%다. 기존 v1 기준선 4/8 = 50%는 그대로 보존한다. 비율 차이는 회귀가 아니라 새 완료 조건이 추가된 결과다.

A0는 실제 무료 VPN·순간 UX·3잔액·추천까지이며 실제 금전 결제는 A1으로 분리한다. 첫 가시 변화 목표는 구현 시작 후 4~6 개발시간, A0 후보는 44~60 개발시간이다. 이는 추정치이며 서버·기기·참여자 대기와 실사용자 검증 시간은 별도다.
