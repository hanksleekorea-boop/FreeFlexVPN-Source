# Galaxy A56 전용 검사·사용성 관찰 보고서 — 2026-08-05

## 한 줄 결론

Galaxy A56은 USB 디버그, IPv4 인터넷, 도메인 이름 확인, IPv6 인터넷에 모두 응답했다. 그러나 이 시점에는 **활성 WireGuard 세션과 VPN 터널 경로 표식이 없어서**, “현재 VPN 보호 중”으로 판정하지 않는다.

## 범위와 개인정보 원칙

- 실제 기기: Galaxy A56 (`SM-A5660`) 한 대만 사용했다. S21+는 이 보고서의 검사·판정에 포함하지 않는다.
- 읽은 것: USB/ADB 승인 상태, Android VPN 전송망 표식, 터널 경로 표식, 일반 인터넷 응답.
- 읽지 않은 것: 사진, 메시지, 연락처, 저장 파일, 계정, IP 주소, VPN 설정값.
- 변경한 것: 없음. 터널의 켜기·끄기, 상시 VPN, 차단 모드 모두 바꾸지 않았다.

1. WireGuard 터널을 켠 상태의 터널 경로·재연결.
2. DNS 누출, 실제 공인 IP 위치, IPv6 누출.

## UI·UX 판정

### 현재 잘 된 점

- 모바일·PC 화면, 공개 QR, Android 시작 안내, 진행 대시보드의 도달 경로가 자동 검사에서 통과했다.
- 상태를 실제 보호 성공처럼 과장하지 않는 화면 계약이 있다.
- A56에서 IPv4·도메인 이름·IPv6 일반 인터넷은 실제로 응답했다.

### 부족한 점과 한계

- 연결 전·후를 실제 서버 검사로 바꾸는 사용자용 화면이 없다. VPN 아이콘·인터넷 응답만으로 보호를 확정할 수 없다.
- 설정을 다시 받거나 폐기하고, 기기별 상태를 한곳에서 정리하는 흐름이 없다.
- 서버의 실시간 상태·속도·혼잡, 실제 사용량, 소진 예측을 정직한 값으로 보여 주지 못한다.
- A56에서도 상시 VPN·차단 모드는 꺼져 있어, 끊김 상황의 안전성은 아직 확인하지 못했다.
- iPhone, DNS/IPv6 누출, 공인 IP 위치는 실제 검증이 남아 있다.
