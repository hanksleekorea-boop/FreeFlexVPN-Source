# Android 실제 기기 연결 기록

날짜: 2026-08-04~2026-08-05

## 사용자가 직접 확인한 사실

- Android의 공식 WireGuard 앱에서 FreeFlexVPN 설정을 가져왔다.
- WireGuard 스위치를 켠 뒤 Yahoo Japan 페이지가 열려 인터넷 접속을 확인했다.
- 스위치를 껐다가 다시 켠 뒤 재연결에 성공했다.

## 아직 확인하지 않은 것

- DNS 누수, IPv6 누수, 킬 스위치, 서버 쪽 최근 핸드셰이크 시간은 별도 확인 전이다.
- iPhone은 당시 사용할 수 없어 확인하지 않았다.
- Windows와 macOS 실제 연결도 확인 전이다.
- 따라서 목표 운영체제 전체 완료나 현재 서버 가동 상태로 확대 해석하지 않는다.

## 화면 사실성 보호

- 고객 화면은 과거 Android 연결·재연결 성공을 표시한다.
- 현재 상태는 `새로 확인 필요`로 표시하며 `현재 연결됨`으로 단정하지 않는다.
- `40_TESTS/test_service_ui_v3.py`의 두 전용 검사가 이 경계를 고정하며 15/15 통과했다.
