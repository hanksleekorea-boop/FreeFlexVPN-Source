# FreeFlexVPN v2.7 R6 증거 사슬 계획

> 상태: `VERIFIED_IMPLEMENTED_LOCAL`  
> 날짜: 2026-08-02  
> 이전 후보·롤백: v2.6 후보 결속 사전검사

## 쉬운 요약

설정 검사 때 확인한 바로 그 서버 설정만 실제 SSH 검사로 넘어갈 수 있게 잠갔다.
설정 파일이나 후보 이름이 중간에 바뀌면 서버에 접속하기 전에 멈춘다.

## 확인한 빈틈

v2.6까지 문서는 설정 전용 검사와 실서버 검사를 같은 candidate ID·같은 설정으로 실행하라고 안내했지만,
CLI는 앞선 설정검사 증거를 요구하지 않았다. 운영 실수나 파일 교체가 있어도 실서버 모드가 시작될 수 있었다.

## 결과 계약

- 실서버 모드는 `--config-evidence` 절대 경로가 필수다.
- 증거는 CONFIG READY 스키마, `mode=config_only`, `configuration_ready=true`, `ready=false`,
  `network_attempted=false`, `contains_secrets=false`를 모두 만족해야 한다.
- 증거의 candidate ID와 설정 SHA-256은 현재 실행과 정확히 같아야 한다.
- 누락·과대·손상 증거와 불일치는 SSH 요청 전에 거부한다.
- 실서버 결과에는 사용한 설정검사 증거의 SHA-256을 기록해 사슬을 역추적할 수 있게 한다.

## 검증

- R6 증거 연결 CLI 5/5 통과.
- 연결 회귀 42/42 통과: CLI 5, R6 판정 9, 제어 런타임 8, 서버 카탈로그 10, SSH 어댑터 10.
- 후보·설정 불일치, 미준비·네트워크 사용 증거, 상대 경로·과대·누락 파일 음성 대조 통과.
- 비밀값·개인정보 스캔은 최종 원장 재생성 뒤 다시 실행한다.

## 증거 경계

- I/L: 구현과 로컬 표적·연결 회귀 증거 있음.
- B/P: 새 공개 앱 릴리스 없음. 공개 앱 정본은 v2.3 그대로다.
- D/U: 실제 서버·대상 기기·독립 사용자 증거 없음.
- v2 기준선: 7/12 = 58.3% 유지.

## 다음 관문

서버 2대 계정을 받은 뒤 외부 `nodes.json`으로 CONFIG READY 증거를 새로 만들고,
그 증거 경로를 `--config-evidence`에 넣어 같은 후보의 실서버 사전점검을 실행한다.

## 롤백

CLI의 `--config-evidence` 필수 조건과 `validate_configuration_evidence`를 제외하면 v2.6 실행 방식으로 돌아간다.
v2.5·v2.6 계획과 증거, 공개 v2.3 앱은 수정하지 않는다.
