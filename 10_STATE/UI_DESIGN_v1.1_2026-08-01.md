## 1. 채택 범위

v1.0의 제품 계약과 9개 화면을 전부 유지하면서 터치 영역 겹침만 교정한 공식 후속 정본이다.

| 화면 | 공식 역할 | 반드시 보여줄 계약 |
|---|---|---|
| 시작 | 한 문장 가치 제안 | 월 1GB 무료 · 충전분 무기한 · 자동결제 없음 |
| 동의 | 최소 정보와 처리 경계 확인 | 저장/비저장 정보 · 개인키를 Telegram에 전송하지 않음 |
| 설정 | WireGuard 연결 안내 | 공식 앱 · QR · 개인키 분리 |
| 홈 | 핵심 상태판 | 무료/충전 잔액 분리 · 연결 상태 · 선택 서버 |
| 국가 선택 | 서버 선택 | 지연시간이 실측 전에는 예시임을 고지 |
| 용량 충전 | 일회성 충전 | 약정/자동결제/만료 없음 · 가격은 지불의사 미검증 설계안 |
| 기기 관리 | 공개키 관리 | 가명 계정당 활성 공개키 최대 2개 · 같은 키 복제 한계 |
| 사용량 | 차감 순서 설명 | 월 무료분 우선 · 충전분 무기한 보존 |
| 내 정보 | 운영 신뢰와 폐기 | 서비스 상태 · 정책 · 기기/계정 삭제 |

## 2. 시각 계약

- 모바일 우선 기준 화면은 `390 × 780`이다.
- v1.0의 네이비·민트·블루 시각 언어와 정보 계층을 유지한다.
- 고정 하단 메뉴를 화면 흐름 안으로 이동해 본문 CTA와 터치 영역이 겹치지 않게 한다.
- 홈 CTA 중심점은 실제 브라우저의 `elementFromPoint`로 자기 자신이 최상위 클릭 대상인지 검사한다.

## 3. 변경 범위

- 연결 오브 크기를 174px에서 150px로 줄여 모바일 세로 공간을 확보했다.
- 하단 메뉴를 절대 위치 오버레이에서 문서 흐름 배치로 바꿨다.
- 제품 정책, 가격팩, 화면 수, 실제 서비스 미연결 고지는 변경하지 않았다.

## 4. 증거 경계

- 로컬 브라우저에서 두 홈 CTA의 클릭 대상 일치와 충전 화면 전환을 확인했다.
- 공개 GitHub Pages와 실제 VPN·결제·계정·실기기 성공은 별도 증거다.
