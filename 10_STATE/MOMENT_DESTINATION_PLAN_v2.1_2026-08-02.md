## 1. 한 문장 제품 정의

사용자가 **지금 있는 국가와 VPN이 필요한 순간**을 고르면, FreeFlexVPN이 **목적 국가와 무료·유료 충전·프리미엄 예정 단계**를 제안하고, 실제 카탈로그에 검증된 서버가 있을 때만 서버 선택을 허용한다.

추천은 연결·가격·콘텐츠 이용 성공 보장이 아니다. 현재 국가와 목적은 브라우저 메모리에서만 사용하며 계정·추천·서버 API로 전송하거나 저장하지 않는다.

## 3. 현재 국가별 추천 보정

| 현재 국가 | 화면에서 해야 할 일 | 이유 |
|---|---|---|
| 중국 | 일반 서버 연결 CTA를 끄고 `전문 서비스 필요` 표시 | 일부 글로벌 서비스가 광범위하게 제한되며 현재 알파는 난독화·검열 우회 호환성을 검증하지 않음 |
| 인도 | 인도 목적지는 실제 규정 적합 서버가 있을 때만 노출 | 인도 CERT-In 지침은 소비자 VPN 제공자에 고객 정보와 로그 보관 의무를 둘 수 있음 |
| 아랍에미리트 | `합법적 목적만` 주의 문구 | VPN 자체를 불법으로 단정하지 않고 불법 목적·범죄 은폐 사용 위험을 분리 |
| 인도·아르헨티나 | 공개 시장·현지화 조사는 허용, 구독 구매 우회는 비지원 | 현지 발급 결제수단·실거주 조건 및 서비스 약관 위반·취소 위험 |
| 그 밖 | 현지 법률과 대상 서비스 약관 확인 | 국가와 서비스마다 조건이 다름 |

자동 위치 추적은 하지 않는다. 사용자가 현재 국가를 직접 선택하며, 선택하지 않아도 30개 카탈로그를 볼 수 있다.

## 4. 추천 엔진 계약

1. 입력: 현재 국가(선택), 목적 국가·본국(선택), 목적 범주, 검색어, 단계.
2. 출력: 순간, 이유, 추천 목적지, 단계, 지원 상태, 현재 행동 가능 여부.
3. `지원/조건부`라도 실제 서버 카탈로그가 미확인 또는 목적 국가 서버가 없으면 비활성.
4. `프리미엄 예정`, `비지원`, `전문 서비스 필요`는 서버가 있어도 비활성.
5. 중국 등 호환성 미검증 제한 환경에서는 일반 서버가 있어도 연결 성공으로 안내하지 않음.
6. 추천 결과는 실제 서버 ID 선택으로만 이어지며 가짜 국가·지연시간·연결 성공을 만들지 않음.
7. 입력값은 네트워크·영속 저장·분석 이벤트에 포함하지 않음.

## 5. 무료·유료 혼합 원칙

- 무료: 공공망 보호, 짧은 진단, 여행 중 저용량 본국 확인. 월 1GB 안에서 핵심 안전 가치를 체험한다.
- 유료 충전: 국가별 조사·현지화 QA·화상회의처럼 데이터가 더 필요한 작업. 충전 용량은 무기한이다.
- 프리미엄 예정: 전용 IP, 성능 측정, 게임 경로, 고용량 스트리밍처럼 운영 품질과 원가가 큰 기능.
- 비지원: 허위 거주지·결제 국가, 약관이 명시적으로 금지하는 국외 우회, 검열 우회 성공을 검증하지 않은 환경.
