- 공식 UI·UX v1.1 채택: 시작·동의·WireGuard 설정·홈·국가·충전·기기·사용량·내 정보 9화면
- 채택 UI v1.1 PWA 공개: `https://hanksleekorea-boop.github.io/FreeFlexVPN/app.html` · 익명 HTTP 3회·브라우저·QR·오클루전 PASS
- 채택 UI 기준 파일은 `60_OUTPUTS/prototype/FreeFlexVPN_app_prototype_v1.1.html`; v1.0 원본은 롤백용 보존, 실제 VPN·결제·계정은 아직 미연결
- exit-node cloud-init v1 생성기·배포 불가 TEST-NET 예시·보안 검사
- SSH는 생성 시 지정한 IPv4 `/32`만 허용, WireGuard UDP만 공개
- 개인키는 서버 첫 부팅 때 서버 내부에서만 생성, 저장소 포함 0
- WireGuard 수신+송신 누적량 1분 집계, 월 1GB 무료 우선 차감, 충전분 무기한 보존
- 미등록·주소변경 피어 fail-closed, 상태 원자 저장, nftables 쿼터 차단 세트
- 저장소 외부 전용 X25519 클라이언트 구성·QR 발급, 공개키 등록·폐기, 재부팅 복원
- Telegram 동의·가명 ID·10분 1회용 claim·2단계 폐기 엔진과 비밀 없는 설정 예시
- Telegram에는 개인키·구성·QR을 보내지 않으며 실제 BotFather 토큰·claim endpoint는 미등록
- VPN 전달 트래픽 TCP/25 차단, 대표 BitTorrent 포트 휴리스틱 차단, fail2ban 건강검사
- HMAC 가명 계정별 활성 WireGuard 공개키 2개 제한; 같은 키 복제는 물리 기기 구분 불가로 명시
- 실제 서버 `cloud-init schema`·부팅·터널 연결은 아직 미검증

## 4. 배포 경로 실측 (2026-07-31 현재 환경)

| 경로 | 실측 | 판정 |
|---|---|---|
| `api.netlify.com` | HTTP 404 | 호스트 도달 PASS, 배포 자격증명 미확인 |
| `api.vercel.com` | HTTP 200 | 호스트 도달 PASS, 배포 자격증명 미확인 |
| `surge.sh` | HTTP 200 | 호스트 도달 PASS, Node/Surge CLI 없음 |
| `api.github.com` | HTTP 200 | 익명 API 도달 PASS, 유효한 push 자격증명 없음 |
| GitHub Pages 공개 진입점 | HTTP·Chrome·CTA PASS | `https://hanksleekorea-boop.github.io/FreeFlexVPN/app.html` |
| 공개 QR | payload·SHA-256 일치 PASS | 앱 공개 URL과 바이트 단위 동일 |
| 실제 VPN runtime entrypoint | 없음 | VPN 연결 P·D·U 검증 불가 |

이전 환경의 HTTP 000 차단은 현재 재현되지 않았다. 따라서 네트워크 탐색은 종료하고,
GitHub Pages는 공개 채널 정본으로 사용한다. 실제 VPN 런타임이 붙으면 같은 저장소의 별도 릴리스로
무캐시 HTTP·Chrome·터널 연결을 다시 판정한다.
