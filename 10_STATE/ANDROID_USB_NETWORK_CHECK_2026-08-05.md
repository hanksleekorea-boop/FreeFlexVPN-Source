# Android USB·네트워크 읽기 전용 확인 — 2026-08-05

## 범위

- 기기: 사용자가 USB로 연결한 Samsung S21+.
- 허용 범위: USB·ADB 연결 상태, VPN 네트워크 표식, 터널 표식, 외부 통신 응답.
- 제외 범위: 사진, 메시지, 연락처, 저장 파일, VPN 설정값, IP 주소, 개인 계정 정보.

## 실제 측정 결과

|항목|결과|뜻|
|---|---|---|
|Windows USB 인식|통과|Samsung S21+와 Android 디버그 장치가 정상 인식됨|
|ADB 디버그 승인|통과|기기 목록에서 `device` 상태 확인|
|Android VPN 전송망 표식|있음|Android 네트워크 서비스에 VPN 표식이 존재|
|외부 인터넷 응답|통과|외부 주소에 1회 응답 성공|
|WireGuard 활성 세션 표식|없음|이 시점의 읽기 결과로는 WireGuard 터널 활성 상태를 증명하지 못함|
|터널 장치 표식|없음|이 시점의 기본 경로에서 `tun`/`wg` 장치 표식을 찾지 못함|
|상시 VPN|꺼짐|자동 상시 VPN은 설정되지 않음|
|차단 모드|꺼짐|VPN이 끊겼을 때 네트워크를 막는 모드는 설정되지 않음|

## 판정

이 결과는 **폰 USB 연결과 일반 인터넷 통신**을 확인한다. 현재 순간의 **WireGuard 터널 보호를 통과로 판정하지 않는다**. 사용자가 WireGuard 앱에서 해당 터널을 직접 켠 뒤, 다음 읽기 전용 확인을 다시 해야 한다.

1. 활성 WireGuard 세션·터널 장치 표식
2. 외부 통신 응답
3. 터널을 껐다 켠 뒤 재연결
4. 필요 시 DNS·IPv6·차단 모드 별도 검사

## 아직 확인하지 않은 것

- iPhone 실제 연결
- DNS 누출, IPv6 누출, 실제 공인 IP 위치
- 끊김 중 차단 모드 동작
- 현재 서버 속도·혼잡·장애 전환

위 항목은 이 문서의 ‘통과’에 포함하지 않는다.
