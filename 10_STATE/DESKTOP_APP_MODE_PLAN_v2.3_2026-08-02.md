> 후보: v2.3 · 2026-08-02

> 사용자 가치: PC·모바일에서 같은 계정·잔액·추천·설정 흐름을 각 화면 크기에 맞게 사용한다.

## 이번 릴리스 한 칸

1. PC의 `?view=app`와 설치형 PWA에서 520~760px의 넓은 앱 본문을 제공한다.
2. 모바일에서는 100dvh 전체 화면을 유지한다.
3. 설치형 PWA는 고정 앱 ID와 scope, `app.html?view=app` 시작 주소를 사용한다.
4. Chrome·Edge·Safari·Firefox별 실제 가능한 설치 안내를 보여준다.
5. 설계 보기↔앱 보기 전환은 되돌릴 수 있고 저장 실패 시에도 화면이 멈추지 않는다.

## 완료 증거

- 표적 계약: 앱 v2.3 18/18, 플랫폼 22/22, 데스크톱 앱 모드 11/11, PWA UI 23/23.
- 전체 회귀: 29개 파일, 384/384.
- 시각 확인: Windows Chromium 1400×900 앱 모드 PNG.
- 음성 대조: 데스크톱 최대 폭을 390px로 변조하면 레이아웃 검사가 실패한다.
- 공개 관문: GitHub Pages CI, 익명 실제 렌더, 무캐시 3회 동일 후보, QR 재디코딩 후 완료한다.

## 정직한 경계

PWA는 관리 앱이다. 실제 VPN 터널은 공식 WireGuard가 실행한다. 서버·로그인·결제·실기기 검증이 없는 공개 후보는 알파 UI이며 실제 VPN 연결 성공을 주장하지 않는다.

## 진척 영향
