# FreeFlexVPN 정책-코드 일관성 계약 v0.2

> 생성: 2026-08-03 · 내부 개발 계약 · 법률 자문 아님 · 공개/동의 수집 금지

이 문서는 `60_OUTPUTS/policy_drafts/FreeFlexVPN_약관_개인정보_국외이전_초안팩_v0.1_2026-08-03.md`의
확정 전 데이터 지도를 코드와 대조한 부록이다. v0.1을 확정본으로 바꾸지 않으며, 공개 전에는 실제 사업자·
공급자·리전·보존 설정을 넣은 독립된 전체 정책 후보와 한국 개인정보 전문가 검토가 필요하다.

## 현재 구현에서 저장하는 값

### 서버·제어 계층

- HMAC-SHA256 가명 계정 식별자
- 동의 여부·정책 버전·동의 시각
- 로그인 수령권과 API 세션의 **SHA-256 해시**·만료·사용/폐기 시각
- WireGuard 공개키, 기기 ID, 배정 내부 주소, 서버 ID, 기기 상태
- 피어별 송수신 누적량, 월 구간, 지갑·차감·세션 요약 원장
- 추천 토큰의 **SHA-256 해시**, 추천 관계·자격 사용량·보상 원장

### 브라우저 계층

- PC 앱 화면 모드와 설치 안내를 닫은 시각은 브라우저 저장소에 남을 수 있다.
- API 세션 원문 토큰은 `sessionStorage` 또는 메모리에만 두며 영구 브라우저 저장소에 두지 않는다.

## 현재 구현에서 저장하지 않는 값

- Telegram 원본 사용자 ID, username, 전화번호, 메시지 원문
- 로그인 수령권 원문과 API 세션 원문을 서버 DB에 저장하지 않음
- WireGuard 클라이언트 개인키
- 방문 사이트, 통신 내용, DNS 질의 원문
- 결제수단 원문·카드정보: PG가 아직 연결되지 않았으며 프로젝트에 저장하지 않음

## 아직 확정되지 않은 값

- 실제 운영 보안로그의 원본 IP·관리자 접속기록 항목과 보존기간
- 계정·백업·감사·결제·환불 원장의 보존 및 파기 주기
- 실제 호스팅·메시징·결제·모니터링 사업자의 법인명, 처리 국가, 리전, 재위탁
- 탈퇴 뒤 잔액·법정 보존·백업 삭제의 충돌 처리와 실제 처리기한
- 만 14세 미만 정책, 책임자, 연락처, 시행일, 변경 고지, 분쟁 관할

위 항목이 확정되고 실제 설정 readback·삭제 왕복·전문가 검토가 끝나기 전에는 “완전한 노로그”,
“정책 준수 완료”, “국외이전 동의 준비 완료”라고 주장하지 않는다.
