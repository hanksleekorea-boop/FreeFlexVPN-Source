## 읽는 법

`P0`는 실제 연결 신뢰를 위해 먼저 필요한 항목, `P1`은 핵심 서비스 신뢰도, `P2`는 채택과 기기간 사용성, `P3`은 포용성과 지원, `P4`는 운영 품질 확장이다. “실시간” 표시는 실제 서버 자료가 연결되기 전에는 절대 화면에 표시하지 않는다.

## 공통 수용 규칙

1. 실제 서버·실기기 자료가 없으면 `확인 불가`, `예정`, `예시` 중 맞는 상태를 보인다.
2. 기능을 만들면 메뉴·홈·오류 화면 중 적어도 한 경로에서 실제로 찾을 수 있어야 한다.
3. 각 기능은 정상 검사와 실패 상황을 의도적으로 만든 음성 검사(고장 상황을 일부러 만들어 제대로 막히는지 보는 검사)를 함께 통과한다.
4. 민감정보·비밀키·실제 IP·원본 설정은 화면, 기록, 문의 복사에 남기지 않는다.
5. P0 완료 전에는 `완전 보호`, `안전 보장`, `실시간` 같은 확정 표현을 사용하지 않는다.
