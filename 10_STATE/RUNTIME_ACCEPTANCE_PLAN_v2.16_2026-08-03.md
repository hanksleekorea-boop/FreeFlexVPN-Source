# FreeFlexVPN T1~T10 실환경 판정 계약 v2.16

> 생성: 2026-08-03 · 증거 등급: 구현/로컬 후보 · 실제 서버/기기/독립 사용자 증거: 0건

## 목적

기존 T1~T10의 짧은 문장을 실제 측정 가능한 입력, 실패 폐쇄형 통과 기준, 증거 출처로 고정한다.
로컬 단위 테스트의 샘플은 실제 기기나 독립 사용자를 대신하지 않는다. 같은 `candidate_id`의 원본
로그·화면·측정값을 프로젝트 밖에서 보존하고 `70_TOOLS/evaluate_runtime_acceptance.py`로 판정한다.

## 공통 실패 규칙

- 필드 누락, `null`, 정의되지 않은 T번호, 후보 불일치, naive datetime은 통과시키지 않는다.
- `origin=actual_target`이 아니면 전 항목의 샘플 값이 참이어도 `adapter_or_demo`다.
- IP·기기·참여자 원본 증거는 프로젝트·Git·이관 ZIP에 넣지 않는다.
- T1~T9는 대상환경 증거, T10은 실사용자 증거다. 하나를 다른 등급으로 대체하지 않는다.
- 모든 항목이 통과해도 원본 증거가 결합되지 않았다면 완료 주장에 사용하지 않는다.

## 실행

```powershell
python -X utf8 70_TOOLS/evaluate_runtime_acceptance.py 'C:\ProgramData\FreeFlexVPN\evidence\runtime-acceptance.json'
```

로컬 회귀만 추가하며 제품 진척 58.3%를 올리지 않는다.
