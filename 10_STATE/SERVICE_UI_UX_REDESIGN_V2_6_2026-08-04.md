# FreeFlexVPN 실제 서비스 UI·UX 재설계 정본 v2.6

> 상태: **DESIGN_READY · IMPLEMENTATION_NEXT**  
> 작성일: 2026-08-04  
> 대상: 공개판 v2.5 → 서비스판 후보 v2.6  
> 기본안: 하나의 반응형 웹앱. 모바일과 PC의 데이터·주소·기능 계약을 나누지 않는다.

## 0. 한 문장 결정

FreeFlexVPN의 첫 화면을 **시제품 기능 전시장**에서 **현재 보호 상태와 다음 한 행동이 분명한 실제 서비스 홈**으로 바꾼다.

브랜드 약속은 다음 한 문장으로 통일한다.

> **매달 내지 말고, 필요한 만큼만 안전하게.**

## 1. 조사 범위와 선정 방식

여기서 “세계 Top 10”은 매출이나 다운로드 순위를 단정하는 표현이 아니다. FreeFlexVPN과의 제품 유사성, 세계적 인지도, 무료·간편·개인정보·완성도 중 배울 점이 분명한지를 기준으로 정한 **제품 설계 비교군 10곳**이다.

| 서비스 | 공식 자료에서 확인한 강점 | FreeFlexVPN에 적용할 것 | 복사하지 않을 것 |
|---|---|---|---|
| [Proton VPN](https://protonvpn.com/free-vpn/download) | 무료 영구, 광고·데이터 제한 없음, 한 번 연결, 신뢰 근거 | 첫 행동을 하나로 줄이고 무료 약속을 바로 보임 | 기능 이름을 첫 화면에 과다 노출 |
| [Windscribe](https://windscribe.com/features/windows) | 내려받기→연결의 짧은 흐름, 무료 용량, 강한 브랜드 말투 | 남은 데이터와 간단한 시작 흐름 | 장난스러운 말투를 그대로 모방 |
| [TunnelBear](https://www.tunnelbear.com/apps) | 국가 선택 후 스위치라는 기억하기 쉬운 조작 | 어려운 VPN 용어를 일상어로 바꿈 | 캐릭터 중심 브랜드 복제 |
| [Mullvad](https://mullvad.net/uk/help/using-mullvad-vpn-app) | 최소 개인정보, 남은 이용시간을 명확히 표시 | 잔액·기기·개인정보 경계를 투명하게 표시 | 시간제 과금 구조 모방 |
| [IVPN](https://www.ivpn.net/en/) | 이메일 없는 시작, 공개 소스, 감사, 과장 없는 설명 | “VPN이 할 수 없는 것”까지 정직하게 안내 | 전문가 설명을 홈에 길게 배치 |
| [hide.me](https://hide.me/en/free-vpn) | 가입 없이 무료 시작, 제한을 비교표로 명시 | 무료와 유료의 차이를 숨기지 않음 | 과도한 경쟁사 비교와 긴 판매 문구 |
| [PrivadoVPN](https://privadovpn.com/freevpn/) | 10GB 잔량 중심 무료 모델, 여러 기기 진입 | 데이터 지갑을 제품 핵심으로 시각화 | 월마다 초기화되는 방식 모방 |
| [Mozilla VPN](https://support.mozilla.org/en-US/kb/what-mozilla-vpn-and-how-does-it-work) | 서버 선택 후 초록 스위치, 익숙한 신뢰 브랜드 | 상태 변화가 색과 문장으로 동시에 보이게 함 | 계정 로그인 전제 |
| [NordVPN](https://support.nordvpn.com/hc/en-us/articles/38467188541201-How-to-set-up-auto-connect-on-the-NordVPN-app) | 가장 빠른 서버 자동 선택, 고급 선택은 뒤로 숨김 | 기본은 추천 서버, 국가는 두 번째 행동 | 지도와 부가 기능을 첫 화면 중심에 배치 |
| [ExpressVPN](https://www.expressvpn.com/vpn-download) | 한 번 연결, 추천 위치, 연결 상태의 높은 완성도 | 큰 주 행동과 추천 서버 조합 | 월정액 구매 압박 |

### 10곳에서 반복된 성공 규칙

1. 홈의 가장 큰 요소는 설명이 아니라 **현재 상태와 한 개의 주 행동**이다.
2. 기본 서버는 자동 추천하고, 직접 고르기는 다음 단계로 둔다.
3. `연결 안 됨 → 연결 중 → 보호됨`이 문장·색·움직임으로 모두 구별된다.
4. 개인정보·감사·로그 정책은 숨기지 않되 주 행동을 방해하지 않는 두 번째 층에 둔다.
5. 무료 한도나 이용 잔액은 숫자로 정직하게 보여준다.
6. 고급 설정은 필요할 때 펼치는 구조로 둔다.

## 2. 현재 공개판이 알파처럼 보이는 정확한 이유

현재 `30_DEPLOY/app.html`은 제품 기능은 풍부하지만 고객 화면과 내부 검토판이 섞여 있다.

1. 상단의 `ALPHA CANDIDATE`, `UI·UX v2.5`, `화면 14개`가 제품보다 제작 상태를 먼저 말한다.
2. 14개 화면 목록, Storyboard, Design rationale가 실제 앱 안에 노출된다.
3. 큰 방패 장식이 첫 화면 공간을 많이 쓰지만 현재 상태나 다음 행동은 알려주지 않는다.
4. 시작·동의·설정·홈·추천·기기·보호 등 서로 다른 단계가 같은 우선순위로 한꺼번에 보인다.
5. 실제 서버와 Android 연결이 준비됐는데도 `서버 0대`, `실제 기능 없음`이 남아 현재 사실과 어긋난다.
6. 웹이 WireGuard 연결을 직접 켤 수 없는 현실과 화면의 큰 전원 버튼이 충돌한다.
7. 예시 잔액·예시 통계·준비 중인 결제가 실제 값처럼 보일 가능성이 있다.
8. PC에서 QR과 큰 통계가 항상 보여 첫 행동의 집중도를 낮춘다.

## 3. 새 정보 구조

화면 14개를 고객에게 그대로 보여주지 않는다. 고객용 메뉴는 4개로 줄인다.

| 메뉴 | 역할 | 포함되는 기존 기능 |
|---|---|---|
| 홈 | 상태 확인과 연결 준비 | 시작, 설정, 보호, 추천 서버 |
| 위치 | 추천·국가 선택 | 순간 추천, 국가 목록 |
| 사용량 | 잔액·충전·기록 | 지갑, 충전, 추천 보상, 사용량 |
| 내 정보 | 기기·정책·도움말 | 기기 관리, 서비스 상태, 정책, 삭제 |

동의 화면은 첫 설정 과정에서 한 번만 나타난다. PC로 이어보기 QR은 `내 기기` 또는 연결 준비 완료 뒤의 보조 행동으로 이동한다.

## 4. 새 첫 페이지 확정안

### 4.1 첫 방문자

```text
┌ FreeFlexVPN                         서비스 상태  도움말 ┐
│                                                          │
│ 필요한 만큼만 쓰는 VPN                                  │
│ 매달 내지 말고, 필요한 만큼만 안전하게.                 │
│ 월 1GB 무료 · 충전분 무기한 · 자동결제 없음             │
│                                                          │
│ [무료 1GB로 시작]      [이미 설정했어요]                 │
│                                                          │
│ ┌ 이 기기의 보호 상태 ────────────────────────────────┐ │
│ │ ● 아직 보호되지 않음                                │ │
│ │ 추천 경로  미국 서부 · 준비됨                       │ │
│ │ [이 기기 연결 준비]                                 │ │
│ │ 웹에서 직접 켜지 않으며 공식 WireGuard로 연결합니다 │ │
│ └──────────────────────────────────────────────────────┘ │
│                                                          │
│ ① 기기 선택   ② WireGuard에 추가   ③ 보호 확인          │
│                                                          │
│ 자동결제 없음 | 활동 로그 없음 | 기기 2대                │
└──────────────────────────────────────────────────────────┘
```

첫 화면에서 반드시 답해야 하는 질문은 세 개뿐이다.

- 무엇인가: 필요한 만큼만 쓰는 VPN
- 나에게 좋은 점은: 월 1GB 무료, 충전분 무기한, 자동결제 없음
- 지금 무엇을 누르는가: 무료 1GB로 시작

```text
┌ 홈 ─────────────────────────────────────────────────────┐
│ 보호 상태: 확인 필요                  [보호 확인]         │
│ 미국 서부 · gcp-usw1-01               [WireGuard 열기]    │
│                                                         │
│ 남은 데이터  1.00 GB                                    │
│ 무료 1.00 GB  |  충전 0 GB                              │
│                                                         │
│ [위치 바꾸기] [사용량 보기] [다른 기기 연결]             │
│                                                         │
│ 최근 상태: 마지막 확인 시각 · 서버 운영 상태             │
└─────────────────────────────────────────────────────────┘
```

### 4.3 PC 넓은 화면

- 왼쪽 220px: 홈·위치·사용량·내 정보만 표시한다.
- 가운데: 보호 상태와 주 행동을 가장 크게 둔다.
- 오른쪽 320px: 잔액, 이번 사용량, 최근 기기를 둔다.
- QR·기간 통계·설명은 접힌 보조 카드 또는 해당 메뉴로 보낸다.
- 모바일은 같은 내용을 한 열로 쌓고, 하단 메뉴 4개를 사용한다.

## 5. 실제 연결 방식에 맞춘 행동 문구

웹페이지가 VPN을 직접 켤 수 있는 것처럼 속이지 않는다.

| 실제 상태 | 주 문구 | 주 버튼 | 보조 설명 |
|---|---|---|---|
| 처음 방문 | 아직 보호되지 않음 | 무료 1GB로 시작 | 약 2분이면 준비됩니다 |
| 기기 선택 전 | 연결할 기기를 골라주세요 | 이 기기 연결 준비 | Android·iPhone·PC 지원 |
| 설정 파일 준비 | WireGuard에 추가할 준비가 됐어요 | WireGuard 열기 | 파일 또는 QR 중 쉬운 방법 제공 |
| 앱 전환 후 | 연결을 켰다면 확인해 주세요 | 보호 확인 | 인터넷 주소와 터널 상태 확인 |
| 확인 성공 | 보호되고 있어요 | 연결 정보 보기 | 서버·확인 시각을 함께 표시 |
| 확인 실패 | 아직 확인되지 않았어요 | 다시 확인 | 인터넷 여부·스위치·설정 파일 순서로 도움 |
| 서버 장애 | 지금은 연결이 어렵습니다 | 상태 다시 확인 | 사실 확인된 장애만 표시 |

`연결됨`은 실제 검사가 성공했을 때만 사용한다. 단순히 버튼을 눌렀다는 이유로 초록색 상태를 만들지 않는다.

## 6. 시각 체계

### 유지

- 한밤색 배경과 민트색 강조는 브랜드 자산으로 유지한다.
- 숫자가 중요한 데이터 지갑, 절제된 어조, 둥근 카드 구조를 유지한다.

### 변경

- 거대한 빛나는 방패를 제거하고 72px 이하의 단순 브랜드 표식으로 축소한다.
- 민트는 주 버튼·보호 성공·핵심 숫자에만 사용한다.
- 배경, 카드, 선, 글자, 성공, 주의, 오류의 7개 의미 색으로 제한한다.
- 제목은 최대 두 줄, 설명은 최대 세 줄, 카드 안 주 행동은 하나만 둔다.
- 모바일 터치 영역은 최소 44px, 본문 대비는 WCAG AA 4.5:1 이상으로 맞춘다.
- 장식용 빛 번짐과 그라데이션은 전체 화면의 10% 이내로 제한한다.
- 실제 로고를 만들기 전까지 이모지·임시 글자 아이콘을 브랜드 표식으로 쓰지 않는다.

## 7. 고객 화면에서 즉시 제거할 것

- `ALPHA CANDIDATE`, 빌드 번호, PC DESK, API READY
- 화면 14개 목록과 화면 번호
- Design rationale, Storyboard, 정직한 프로토타입 설명 카드
- `서버 0대`, `실제 VPN 서버·결제·계정 기능 없음`이라는 오래된 전면 문구
- 앱 모드 전환, 처음부터 보기 같은 검토자용 조작
- 실제 자료와 구별되지 않는 예시 통계·가짜 잔액
- 첫 화면 상시 QR

검토 기능은 삭제하지 않고 공개 기본 주소에서 숨긴다. 내부 검토 전용 주소 매개변수 `?review=1` 또는 별도 내부 파일로 보존한다.

## 8. 서비스판 개발 열차

| 칸 | 화면에서 보이는 변화 | 필수 검사 | 완료 조건 |
|---|---|---|---|
| UX-1 서비스 껍질 | 검토판 제거, 4메뉴, 새 첫 화면 | 390·1280·1920 화면, 첫 CTA 도달 | 내부 용어 0개, 주 행동 1개 |
| UX-2 실제 상태 | 서버·설정·보호 확인 결과 표시 | 성공·실패·서버 장애 상태 검사 | 가짜 연결 상태 0개 |
| UX-3 데이터 지갑 | 무료·충전 잔액과 사용량 | 무료 우선 차감, 값 없음·오류 검사 | 예시 값이 실데이터처럼 보이는 경우 0개 |
| UX-4 신뢰·도움 | 정책, 서비스 상태, 실패 복구 | Android 재연결, iPhone 가능 시 실기기 | 막힌 사용자가 도움 경로를 찾음 |
| UX-5 공개 검증 | 정식판 배포와 실제 사용자 검사 | 전체 회귀, 공개 주소, QR 해독 | 기존 Android 성공 유지 |

### 권장 구현 순서

1. 기존 공개판과 Android 실연결 증거를 기준선으로 고정한다.
2. 검토판 기능을 `review` 모드로 분리한다.
3. 새 서비스 껍질과 첫 화면을 만든다.
4. 현재 GCP 서버 상태와 생성된 기기 설정을 새 홈에 연결한다.
5. 데이터 지갑에서 실값이 없는 부분은 `아직 측정되지 않음`으로 표시한다.
6. 모바일·PC·키보드·화면 읽기·공개 주소를 한 번에 재검사한다.

## 9. 합격 기준

### 5초 이해 검사

처음 본 사람이 5초 안에 다음 세 질문에 답할 수 있어야 한다.

- 이 서비스는 무엇인가?
- 월정액 VPN과 무엇이 다른가?
- 지금 무엇을 누르면 되는가?

### 행동 검사

- 처음 사용자 주 버튼은 한 화면에 정확히 하나다.
- Android 사용자가 설명 없이 60초 안에 연결 준비 방법을 선택한다.
- 이미 설정한 사용자는 두 번 이내의 행동으로 WireGuard 열기 또는 보호 확인에 도달한다.
- 오류가 나면 같은 화면에서 다음 해결 행동을 알 수 있다.

### 정직성 검사

- 서버 수, 상태, 잔액, 사용량, 연결 여부는 실제 자료 또는 명시된 `측정 전`만 표시한다.
- 버튼을 눌렀다는 이유로 보호됨 상태를 만들지 않는다.
- 가격과 결제가 실제로 연결되기 전에는 구매 버튼 대신 `준비 중` 또는 관심 알림만 제공한다.

### 품질 검사

- 390px, 1280px, 1920px에서 가로 넘침이 없다.
- 키보드만으로 모든 행동에 도달한다.
- 글자 대비 4.5:1, 터치 영역 44px 이상을 지킨다.
- Android의 기존 실제 연결과 껐다 켠 뒤 재연결이 계속 성공한다.
- iPhone 실기기가 생기면 동일한 설정·연결·재연결 검사를 추가한다.

## 10. 최종 제품 원칙

FreeFlexVPN은 “또 하나의 초록색 전원 버튼 VPN”이 아니다. 차별점은 다음 세 가지를 한 화면에서 정직하게 증명하는 데 있다.

1. **구독하지 않는다:** 자동결제 없이 필요한 만큼만 쓴다.
2. **남은 것이 사라지지 않는다:** 충전분은 기간이 아니라 데이터로 보존된다.
3. **보호 상태를 꾸미지 않는다:** 확인된 사실만 보여준다.

이 세 가지가 첫 화면에서 보이지 않는 디자인은 아무리 화려해도 채택하지 않는다.
