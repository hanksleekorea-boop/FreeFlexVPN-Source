# FreeFlexVPN × 카카오VPN 비하향 통합 설계 v1

작성: 2026-08-19 · 상태: **기획·설계 통합 완료 / 기능·서버·가격 공개 전**

## 1. 통합 결론

카카오VPN을 FreeFlexVPN의 대체 제품이나 별도 핵심 엔진으로 넣지 않는다. FreeFlexVPN의 검증된 계정·지갑·추천·서버 목록·보호 상태·PC/모바일 화면을 공통 기반으로 유지하고, 그 위에 중국 체류 한국인의 카카오톡·LINE·통화 사용을 위한 **카카오 특화 프로필**을 추가한다.

통합 이름은 문서 안에서 `Kakao Connect`로 부른다. 이 이름은 외부 상표·출시명이 아니라 내부 기능 식별자다. 실제 외부 이름은 상표·법률 검토 전에는 확정하지 않는다.

## 2. 비하향 원칙

다음 항목은 카카오 특화 설계 때문에 낮추거나 제거하지 않는다.

1. FreeFlexVPN의 월 무료 1GB, 무기한 충전 잔액, 자동결제 없음.
2. 무료→추천 보상→충전 순서의 3지갑과 사건 중복 차감 방지.
3. 양쪽 500MB 추천 보상, 보호 확인과 누적 100MB 이후 지급, 자기·순환·중복 추천 차단, 월 5회 상한.
4. 공식 WireGuard 앱을 쓰는 기존 PC·모바일 흐름과 현재 공개 URL·서비스 QR.
5. 기존 Android `ffvpn`과 모든 기존 프로필의 무삭제·무덮어쓰기 원칙.
6. 터널·경로·DNS 근거가 모두 있을 때만 `protected`로 표시하는 정직한 보호 상태.
7. 개인키·원본 설정·실제 IP·계정 원문·열쇠 문자열·접속 원문 기록 비저장.
8. 키보드·큰 글씨·고대비·화면읽기·모바일 기존 흐름의 접근성 기준.
9. 실제/자동/가상/추정 증거를 분리하고 실제 증거 없이 완성도 점수를 올리지 않는 원칙.
10. 중국은 현재 `specialized_required` 상태를 유지하며, 실제·법률 검증 전에는 접속 성공을 약속하지 않는다.
11. Drive B는 연결·구성·읽기·쓰기·복제·복원·삭제 대상으로 사용하지 않는다.

## 3. 기능별 상위 기준 선택

| 영역 | FreeFlexVPN 현재 강점 | 카카오VPN 강점·아이디어 | 통합 후 기준 |
|---|---|---|---|
| 제품 범위 | 여행·공용망·가벼운 업무 범용 | 중국 체류자의 메시지·통화 집중 | 범용 제품 안의 별도 특화 프로필 |
| 고객 화면 | 공개 반응형 PWA, PC 작업대, 정직한 빈 상태 | 카카오톡·LINE·보이스톡 사용 순간 | 기존 화면에 검증 전 비공개 특화 카드만 추가 |
| 기본 경로 | 실제 증거가 있는 WireGuard 후보 | VLESS/REALITY + Hysteria2 듀얼 후보 | WireGuard 기본 유지, 두 후보는 연구용 제공자 어댑터로 격리 |
| 계정·사용량 | 월 1GB, 3지갑, 무기한 충전, 사건 중복 방지 | 월 500MB와 상한·유예 아이디어 | 기존 원장을 유지하고 일 상한·유예는 선택 정책 후보로만 검증 |
| 추천 | 실제 원장과 부정 추천 방지 | 친구추천을 주요 성장 채널로 사용 | 기존 원장을 재사용하고 새 추천 엔진을 만들지 않음 |
| 서버 | 최신 health·계약·출구 검증 뒤에만 노출 | 서울·도쿄·홍콩 다중 노드와 자동 전환 | 기존 서버 카탈로그를 확장하되, 검증된 특화 노드만 별도 등급으로 노출 |
| 개인정보 | 비밀값·실제 IP·원문 진단 비저장 | 이메일만, 접속 로그 미보존 | 더 엄격한 기존 기준 유지; 이메일조차 가명 계정 ID 뒤에 둠 |
| 운영 | 실패-닫힘 원장·교체 보호·증거 관문 | 1인 운영과 주 2시간 목표 | 기존 자동화·감사 구조 위에 운영시간 지표만 추가 |
| 가격 | 월 1GB + 팩 3/10/30/100/300GB | 1,500원 팩·1,800원 팩·500원/GB가 충돌 | 기존 가격 유지; 카카오 가격은 파일럿 전까지 미결정 |
| 품질 증거 | 전체 자동검사와 실제 기기 증거 분리 | 보이스톡 5분×3회와 6주 파일럿 | 기존 증거 체계 + 실제 Android 메시지·통화 품질 관문 추가 |

## 4. 통합 구조

### 4.1 공통 기반

- 계정·청구: `wallet_ledger.py`, `quota_ledger.py`, `quota_agent.py`
- 추천: `referral_ledger.py`
- 서버: `server_catalog.py`
- 상태·증거: 기존 보호 상태 엔진, 런타임 증거, 상용화 통과 조건
- 화면: 현재 반응형 PWA와 PC 작업대

카카오 특화 기능은 이 공통 기반을 호출한다. 카카오 패키지의 `billing-guard.py`를 운영 과금 엔진으로 가져오지 않는다. 이유는 실제 패널·SSH 경로에 결합돼 있고, 다중 인바운드 상태 변경과 저장 실패에 대한 통합 시험이 없으며, FreeFlexVPN의 원자적 3지갑·사건 중복 방지보다 검증 수준이 낮기 때문이다.

### 4.2 제품 정책 계층

`product_profile = kakao_connect`는 다음 정책만 추가한다.

- 목적: 메시지 알림·텍스트·사진·통화의 가벼운 사용
- 비지원: 4K·대용량 다운로드·P2P·우회 성공 보장
- 지역 상태: 중국에서는 법률 확인과 실제 호환성 근거가 모두 있어야 후보 노출
- 가격 상태: `unresolved`, 외부 결제·홍보 금지
- 추천: 기존 FreeFlexVPN 추천 원장 사용
- 개인정보: 접속 원문 로그 없이 합산 사용량과 성공/실패 근거만 허용

### 4.3 경로 제공자 계층

| 제공자 | 현재 상태 | 승격 조건 |
|---|---|---|
| WireGuard | FreeFlexVPN 기본, 기존 실제 증거 보유 | 기존 G1 보호 범위 완결 유지 |
| VLESS + XTLS-REALITY | 연구 후보, 실제 증거 0 | 법률 검토, 서버 격리, 지원 클라이언트, 중국 실제 연결·복귀 검사 |
| Hysteria2 | 통화용 연구 후보, 실제 증거 0 | 위 조건 + UDP 품질·중복 전송·일 상한·장애 복구 검사 |

두 연구 후보는 WireGuard를 대체하지 않는다. 같은 계정·지갑·추천을 사용하더라도 경로별 구성·키·클라이언트·상태 증거는 분리한다. 한 경로의 성공을 다른 경로의 성공으로 승계하지 않는다.

## 5. 가격·과금 충돌 처리

카카오 인수 자료에는 세 안이 공존한다.

1. 월 500MB + 1.5GB 1,500원 팩
2. 월 500MB + 1.5GB 1,800원 팩
3. 월 500MB 뒤 500원/GB 순수 종량제

세 안은 모두 미검증 가정이다. 통합은 FreeFlexVPN의 월 1GB·기존 팩·무기한 충전을 바꾸지 않는다. 카카오 특화 가격은 다음 실제 자료를 얻은 뒤 별도 정책으로 결정한다.

- Android 실제 메시지·통화 사용량
- 중복 전송을 포함한 서버 실측 원가
- 무과금 비율·재충전율·30일 유지율
- 결제 수수료·환불·법률 검토 결과

## 6. 출시 통과 조건

`Kakao Connect`는 다음 조건을 모두 닫기 전 공개·결제·완료 표기를 금지한다.

1. **K0 설계:** 이 문서와 비하향 자동 계약 통과.
2. **K1 로컬 정책:** 기존 원장·추천·서버를 재사용하는 정책 인터페이스와 모의 입력 검사.
3. **K2 화면:** 기존 모바일·PC 흐름을 깨지 않는 비공개 특화 카드, 미확인·법률 안내·비지원 범위 표시.
4. **K3 제공자 후보:** 각 경로의 구성·상태·폐기·복귀가 기존 프로필과 분리됨.
5. **K4 가상 평가:** 1,000명 가상 페르소나로 온보딩·가격 이해·오류 복구 가설 확인. 실제 고객 증거로 표현 금지.
6. **K5 실제 기기:** Android에서 카카오톡·LINE 로그인/채팅/사진/통화, DNS·일반 웹·터널 해제 복귀, 기존 `ffvpn` 보존 확인.
7. **K6 파일럿:** 제한 사용자와 비용 상한 아래 성공률·유지율·운영시간·원가 측정.
8. **K7 상용 검토:** 법률·결제·환불·개인정보·지원·되돌리기 실제 왕복.

## 7. 중단 조건

- 기존 FreeFlexVPN 공개 앱·QR·가격·원장·프로필을 변경해야만 통합할 수 있는 경우
- 실제 근거 없이 중국 접속·통화 성공을 약속하게 되는 경우
- 사용자별 접속 원문·목적지·실제 IP·개인키 저장이 필요한 경우
- 기존 접근성·모바일 흐름·보호 상태 정직성을 낮추는 경우
- 가격 미결정 상태에서 결제 또는 외부 홍보를 연결하는 경우
- 실제 Android 시험에서 일반 인터넷 복귀 또는 기존 프로필 보존을 확인하지 못한 경우

## 8. 현재 판정

- [확인] FreeFlexVPN 공통 기반과 공개 앱은 그대로 유지된다.
- [확인] 카카오VPN의 기획 강점이 별도 특화 프로필·다중 경로 연구·파일럿 지표로 흡수됐다.
- [확인] 가격·경로·상용 완성도는 올라갔다고 표시하지 않는다.
- [미확인] 중국 실제 접속, 카카오톡·LINE·보이스톡 품질, VLESS/REALITY, Hysteria2, 법률·결제 적합성.

따라서 이번 통합은 **K0 기획·설계 통과**이며, 실제 제품 기능·공개·가격 확정은 아니다.
