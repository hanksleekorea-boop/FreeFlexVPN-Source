## 1. 제품의 한 문장

FreeFlexVPN은 매달 구독을 관리하고 싶지 않은 사람이 여행·공용 Wi-Fi·짧은 업무에서 필요한 순간에, 실제 보호 여부와 한계를 숨기지 않고 쓸 수 있게 하는 VPN 서비스다.

## 2. 고객과 사용 순간

| 고객 | 대표 상황 | 첫 화면이 해야 할 일 |
|---|---|---|
| VPN 초보자 | 처음 연결·QR 가져오기에서 막힘 | 상태와 다음 행동을 한 문장으로 제시 |
| 여행자·공용망 사용자 | 공항·호텔·카페 Wi-Fi | 가까운 정상 경로와 보호 범위를 알림 |
| 다른 국가의 공개 웹을 확인하는 사용자 | 지역별 공개 화면 확인 | 실제 제공 지역만 보이고, 접속 성공을 보장하지 않음 |
| 연결 문제를 푸는 사용자 | 사이트·네트워크 경로 문제 | 대체 경로와 캡티브 포털 안내 |
| 여러 기기를 쓰는 사용자 | Android·iPhone·PC 전환 | QR 이어보기·기기 상태·안전한 해지 |

고화질 스트리밍, 대용량 내려받기, P2P, 특정 서비스 우회 보장, 고강도 검열 우회는 이 제품이 먼저 약속하는 범위가 아니다.

## 3. 고객에게 하는 네 가지 약속

1. 실제로 보호되는지, 연결만 됐는지, 아직 모르는지를 구분한다.
2. 막혀도 1분 안에 다음 행동을 찾게 한다.
3. Android·iPhone·PC·여러 기기를 안전하게 이어 쓴다.
4. 서버·사용량·장애·개인정보의 근거와 모르는 것을 함께 보여 준다.

## 4. 화면과 서비스 원칙

### 4.1 상태는 사실대로

엔진의 다섯 상태(`setup_needed`, `disconnected`, `checking`, `limited`, `protected`)를 유지한다. `protected`는 터널·경로·DNS 같은 필수 근거가 모두 있을 때만 쓴다. 근거가 부족하면 여섯 번째 상태를 만들지 않고 `연결됨, 보호 상태 확인 불가`라고 설명한다.

| 상황 | 허용 문장 | 금지 문장 |
|---|---|---|
| 근거 전부 확인 | 보호 확인됨 + 시각·근거 | 완전 안전 보장 |
| 연결됐지만 근거 부족 | 연결됨, 보호 상태 확인 불가 | 보호됨 |
| 검사 중 | 확인 중 + 취소/재시도 | 거의 안전함 |
| 운영 자료 없음 | 알 수 없음 / 준비 중 | 정상 / 실시간 |
| iPhone 실기기 전 | 안내 제공, 실기기 확인 전 | iPhone 검증 완료 |
| 가상 사용자 분석 | 사용성 가설 | 고객 조사 결과 |

### 4.2 안전과 개인정보

- WireGuard 암호화 통로, DNS·IPv6 보호 또는 명시적 안전 차단, 운영체제별 차단 모드와 재연결을 목표로 한다.
- 개인키, 원본 설정, 실제 IP, 계정, 열쇠 문자열, 원문 진단 기록은 화면·기록·공유에 남기지 않는다.
- 기기 밖으로 보내는 행동은 필요한 최소한만, 기록·알림·분석은 기기 안 또는 명시 동의가 기본이다.
- 기기 해지·재발급·전체 초기화는 영향과 되돌릴 수 없음을 먼저 보여 준다.
- 수집·미수집 항목, 삭제·내보내기, 요청 상태는 고객이 찾을 수 있는 경로에 둔다.

### 4.3 모바일과 PC

- 모바일은 보호 상태·마지막 확인·다음 행동·복구를 한눈에 보이게 한다.
- PC는 1024px 이상에서 기기·상태·사용량/이력·QR 이어보기를 함께 보인다. 키보드로 핵심 행동을 할 수 있어야 한다.
- 1024px 미만의 모바일 흐름은 기존 모습 그대로 보호한다.
- 색만으로 상태를 나누지 않고, 화면읽기·큰 글씨·고대비·움직임 줄이기·느린 망을 함께 고려한다.

### 4.4 데이터·가격·추천의 한계

- 무료 기본량과 필요한 만큼만 충전하는 방향, 자동 결제·만료 공포를 피하는 방향은 유지한다.
- 실제 결제·환불·세금은 별도 승인 전에는 비활성 또는 연결 대기라고 명시한다.
- 추천은 연락처가 아니라 안전한 임의 코드로 하며, 자기·순환·중복 지급을 막는다.
- 가짜 잔액·가짜 서버 위치·가짜 지연시간·가짜 성공률로 화면을 채우지 않는다.

## 6. 현재 사실과 정직한 범위

- 반응형 화면, Android 설정 안내, QR, 기본 진행 현황 화면은 있다.
- Android A56에서 공식 WireGuard 앱의 설정 가져오기·VPN 권한·활성 터널·IPv4·DNS·꺼짐 뒤 재연결과 서버 최신 악수를 확인했다. IPv6은 현재 기기·망에서 도달하지 않았고, 외부 경로 일치·차단 모드는 미검증이다.
- iPhone 실기기 확인과 실제 운영 서버 자료 연결은 아직 없다.
- 가상 1,000명 분석은 설계 가설이며 실제 고객 설문이 아니다.
- 실제 출처·갱신 시각·추정 여부가 없는 서버·사용량·장애 수치는 확정값으로 보이지 않는다.

## 7. 완료와 중단 조건

보호를 잘못 표시함, 비밀값·실제 IP 노출, 모바일 기존 흐름 손상, 다른 기기 오해지, 근거 없는 실시간 표시, 핵심 행동의 접근성 실패가 생기면 다음 묶음으로 넘어가지 않는다. 장식 애니메이션·부가 차트·추천 설명 확장은 먼저 줄일 수 있지만, 상태 정직성·개인정보 가림·삭제권·긴급 해지·기본 접근성은 줄이지 않는다.

## 10. 실제 Android 증거와 P1 반영 (2026-08-10)

- 실제 증거: Android 실기기에서 WireGuard 설정 가져오기, VPN 권한, 터널 활성, IPv4·DNS 통신, 끈 뒤 재연결, 서버 최신 악수를 확인했다. 개인 설정·실제 IP 값은 기록하지 않는다.

- P1-REAL-STATUS-001: 공개 화면의 `두 번째 서버 준비` 문구가 실제 서버·Android 연결 증거와 어긋났다. 로컬 코드에서 `운영 자료 연결 전`과 실기기 확인 범위로 바로잡고 화면·자동·40명 선별 가상 페르소나 검사를 통과했다. 최신 정적 후보 18개를 기존 Cloud Storage 공개 버킷에 반영하려 했으나 업로드가 0/18 오류로 끝났고, 현재 세션에는 버킷 메타데이터 읽기 권한도 없다. 따라서 최신 공개 앱·QR의 HTTP, 파일 지문값, QR 해독, `no-cache` 대조는 **대기**이며 이전 공개판은 보존한다.

## 12. 상용 신뢰 증거 보강 제안 채택 (2026-08-20)

`10_PLAN/FREEFLEXVPN_READINESS_IMPROVEMENT_PROPOSAL_v1_2026-08-20.md`를 채택해 이 기획의 상용화 우선순위를 보강한다. 이 채택은 새 기능·가격·프로토콜·서버를 즉시 공개하거나 실제 검증이 끝났다는 뜻이 아니다.

### 12.1 유지할 제품 결정

1. 기존 FreeFlexVPN은 여행·공용망·가벼운 업무의 범용 VPN/PWA로 유지한다.
2. 공식 WireGuard 기본 경로, 월 무료 1GB, 무기한 충전, 자동결제 없음, 기존 추천 원장과 공개 앱·QR을 낮추지 않는다.
3. Kakao Connect는 별도 특화 프로필로만 유지한다. VLESS/REALITY·Hysteria2·카카오 전용 가격은 법률·실제·원가 증거 전까지 연구 후보/미결정이다.
4. 기존 Android `ffvpn`과 다른 프로필은 삭제·덮어쓰기·자동 활성화하지 않는다. Drive B도 영구 제외한다.

### 12.2 새로 고정하는 고객 약속

1. `protected`는 실제 터널·경로·DNS 등 필요한 근거가 모두 있을 때만 표시한다.
2. 연결 실패·QR/파일 오류·오프라인·복구는 화면, 도움말, 가린 진단에서 같은 다음 행동을 제공한다.

### 14.5 핵심 사용자 흐름

#### 흐름 A — 처음 연결

1. 사용자는 지원 Android 판·가격·무료 1GB·수집 정보·자동 갱신 없음을 먼저 본다.
2. 최소 계정 또는 기기 식별을 만들고 이용약관·개인정보 선택을 분리해 동의한다.
3. 서버가 기기 전용 WireGuard 설정을 만들고 만료 시각과 기기 이름을 붙인다.
4. 화면은 개인 설정 QR과 서비스 주소 QR을 명확히 구분한다.
5. 공식 WireGuard 가져오기 뒤 연결하고, 외부 경로·DNS·확인 시각이 일치할 때만 `보호됨`으로 표시한다.
6. 하나라도 없으면 `부분 보호` 또는 `확인 필요`로 표시하고 다음 행동을 제공한다.

#### 흐름 B — 사용량과 충전

1. 무료→충전→추천 순서와 실제 차감 순서를 화면에 공개한다.
2. 모든 차감은 고유 사건 ID로 한 번만 처리한다.
3. 월 무료량은 새 달에 다시 생기며 충전 잔액은 만료시키지 않는다.
4. 결제 전 총액·세금·환불·자동 갱신 없음과 결제 사업자를 표시한다.
5. 결제 성공과 잔액 반영이 어긋나면 자동 재처리하지 않고 `검토 중`으로 닫는다.

#### 흐름 C — 실패와 복구

1. 설정 만료, 서버 불가, DNS 실패, 인터넷 없음, 권한 거부, 잔액 부족, 결제 실패, 증거 오래됨을 구분한다.
2. 각 오류는 한 화면에서 원인·자료 영향·다음 한 행동·지원 연결을 보여 준다.
3. 기존 프로필을 자동 삭제하거나 다른 기기를 폐기하지 않는다.
4. 복구 실패 시 VPN을 끄고 일반망이 돌아왔는지 확인하는 안전 절차를 제공한다.

#### 흐름 D — 삭제와 탈퇴

1. 사용자는 로컬 기록만 삭제, 특정 기기 폐기, 계정 자료 삭제, 계정 종료를 구분한다.
2. 삭제 전에 잔액·환불·재사용 불가 영향을 보여 준다.
3. 서버 처리 상태와 완료/부분 실패 범위를 영수증으로 제공한다.
4. 법정 보관 자료는 항목·근거·파기 예정일을 별도로 표시한다.

### 14.6 화면 정보 구조

모바일 5탭은 `홈·위치·사용량·기기·더보기`를 유지한다. 홈은 보호 카드와 1분 복구, 위치는 검증된 서버와 상태, 사용량은 세 잔액과 결제, 기기는 프로필 수명주기, 더보기는 지원·법률·삭제·접근성을 맡는다.

PC 웹은 같은 자료를 사용하되 `현재 보호·기기/프로필·사용량/결제·서버 상태·지원/증거`를 넓은 화면에서 동시에 비교할 수 있게 한다. PC 웹 자체를 Windows VPN이라고 부르지 않는다. 2단계 Windows 터널이 실제 통과한 뒤에만 PC VPN 지원으로 표시한다.

모든 자료 화면은 `loading`, `empty`, `ready`, `stale`, `partial`, `error`, `cancelled`, `recovery` 상태를 가진다. 빈 화면과 오류 화면에서 성공처럼 보이는 기본 숫자를 만들지 않는다.

### 14.7 상용 품질·보안·법적 계약

- 보호 상태는 실제 터널 하나만으로 완료되지 않는다. 지원 범위 안에서 외부 경로·DNS·검사 시각이 맞아야 한다.
- 킬 스위치, IPv6, WebRTC는 지원 여부와 시험 결과를 플랫폼별로 표시한다.
- 모든 쓰기 요청은 중복 처리 방지 키, 현재 판번호, 권한 확인, 감사 사건을 가진다.
- 개인키는 가능한 한 기기에서 생성하며 서버·로그·분석·고객지원 자료에 남기지 않는다.
- 비밀값 검사는 인터넷 공개 전과 코드 보관소에 올리기 전에 모두 통과해야 한다.
- 약관·개인정보·결제·환불 문구는 실제 운영 주체와 처리 흐름이 확정된 뒤 법률 검토를 받는다.
- 검열 우회, 특정 국가 성공, 완전 익명, 무로그는 실제 범위를 넘어 보장하지 않는다.
- 실제 장애·보안 사고·결제 장애는 고객 상태판과 지원 절차에 연결한다.

### 14.8 1단계 완전 상용화 통과 조건 CC-GATE-1

### 14.9 단계별 제품 완성 정의

- **1단계 — 완전 상용판:** Android 실제 VPN과 모바일·PC 관리 웹을 일반 고객에게 판매·지원·환불·삭제할 수 있다. iPhone·Windows·Kakao Connect는 지원 밖이라고 명확히 표시한다.
- **2단계 — 선두권 확장판:** iPhone·Windows, 여러 지역, 개인화, Kakao Connect 제한 파일럿, 독립 투명성 보고를 추가한다. 1단계 고객과 권리를 그대로 유지한다.
- **3단계 — 세계 최고 후보:** 장시간·다중망·장애 훈련·안전한 대체 경로·동일 과업 재비교로 차별화를 실제 증거로 만든다.

### 14.11 채택 결과

`CC-BASE-01~10`, `CC-01~24`, `CC-GATE-1`을 FreeFlexVPN의 최신 제품 계약으로 채택한다. 이 채택은 방향과 완료 조건을 확정한 것이며 실제 기능·실기기·결제·법률·운영 증거를 새로 만든 것은 아니다. 현재 개발 75%, 모바일 58%, PC 60%, 상용화 미완료는 그대로 유지한다.
