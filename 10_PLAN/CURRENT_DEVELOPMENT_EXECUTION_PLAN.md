## 2. 시작 전 안전 절차

1. `.project-continuity`의 현재 상태·잠금·최근 기록을 확인한다.
2. 수정 전 전체 재검사(회귀)를 실행해 손대기 전 상태를 남긴다.
3. 수정할 파일을 잠금 기록에 적고, 다른 작업자의 유효한 잠금이 있으면 멈춘다.
4. 한 묶음의 로직과 화면 문구 증가량을 1:1로 견적하고 완료 후 실제 크기를 측정한다.
5. 공개·비용·기기 설정 변경은 별도 승인 없이는 하지 않는다.

## 3. 공통 구현 계약

| 영역 | 반드시 지킬 것 |
|---|---|
| 보호 상태 | 다섯 엔진 상태를 유지하고, 근거가 빠지면 `protected`를 표시하지 않음 |
| 운영 자료 | 출처·갱신 시각·추정 표식이 없으면 빈 화면 또는 준비 중으로 표시 |

## 5. 한 묶음의 완료 조건

화면에서 보이는 변화, 실제 진입 경로, 정상 검사, 일부러 틀린 입력을 넣어 검사가 잡아내는지 확인하는 검사, 전체 재검사, 용량 측정, 실제/자동/가상/고객 증거 구분, 공개 완료 또는 공개 대기 표기를 모두 만족해야 한다.

보호 오표시, 비밀값·실제 IP 노출, 모바일 흐름 손상, 다른 기기 오해지, 근거 없는 정상·실시간 표시, 키보드·보조기술 핵심 행동 실패가 나오면 현재 묶음의 노출을 되돌리고 다음 묶음으로 넘어가지 않는다.
