# FreeFlexVPN Public Pages

FreeFlexVPN의 공개 제품 안내, 알파 UI v2.0 PWA, 검증된 비용 설계 화면입니다.

- 월 1GB 무료
- 필요한 만큼 충전
- 충전 데이터 유효기간 무제한
- 라이트 VPN 사용자 대상

현재 저장소는 공개 정적 페이지 전용입니다. VPN 서버 자격증명과 내부 사업 자료는 포함하지 않습니다.

- 공개 앱: `app.html`
- 앱 QR: `app-qr.png` (디코딩 payload와 SHA-256은 `app-qr-evidence.json`)
- 실제 VPN·결제·계정 발급은 아직 연결되지 않은 정직한 서비스 셸입니다.
