AI는 "만드는 시간"을 거의 0으로 만들지만, "기다리는 시간"은 못 줄입니다. 그래서 하한이 0일이 아니라 1일입니다.

왜 1일이 가능한가 — 새로 짤 코드가 없습니다

이미 완성된 모듈로 전부 대체됩니다
  • VPN 서버 → 커널 WireGuard (리눅스 내장)
  • 사용자·쿼터·만료 관리 → Remnawave / 3x-ui 패널 (설치 스크립트 1줄)
  • 1GB 무료 상한 자동 차단 → 패널 내장 기능과 잔액 원장 연동
  • 설정 QR·구독링크 발급 → 패널 내장
  • 가입·인증·안내 봇 → 오픈소스 텔레그램 봇
  • 클라이언트 앱 → 공식 WireGuard 앱 (앱스토어 심사 불필요)
  • 모니터링 → Uptime Kuma (도커 1줄)

직접 만드는 것은 랜딩페이지와 안내문뿐입니다. 그래서 "개발 기간"이 아니라 "설정 시간"이 됩니다.

1일 오픈에서 반드시 포기해야 하는 것
  • 휴대폰 인증 — 1일차는 이메일 인증으로 시작하고, 다중계정이 보이면 그때 SMS를 붙입니다
  • 공개 모집 — 초대 링크로 50~100명만. 공개 오픈은 남용 패턴을 2~3일 본 뒤
  • 다국가 — 1일차는 일본 노드 1대. 국가 확장은 원가가 거의 안 오르니 나중에 언제든
소요 시간은 오픈소스 설치 스크립트 기준 추정이며 실측이 아닙니다. 호스팅 계정 검증·DNS 전파는 업체와 상황에 따라 달라집니다. SMS 발신번호는 개인 계정 + 본인 휴대전화면 문자 본인인증만으로 등록 가능하고, 타인·일반번호는 통신서비스 이용증명원 등 서류 심사가 필요합니다(솔라피 공식 안내 기준).
