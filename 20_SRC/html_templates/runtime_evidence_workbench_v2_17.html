이 도구는 선택한 파일을 브라우저 안에서만 해시합니다. 서버로 보내지 않습니다. 그래도 개인키·토큰·결제수단·실명은 먼저 제거하세요. 생성된 JSON만으로 통과하지 않으며 Python 판정기가 같은 폴더의 원본 파일을 다시 검증합니다.

1. 같은 후보에 묶기

시각은 이 브라우저의 현지 시간에서 ISO-8601로 변환됩니다. 후보 ID는 실제 서버·기기·사용자 관찰 전체에서 같아야 합니다.

2. 원본 증거 파일 선택

각 T행에 파일이 필요합니다. 같은 원본이 여러 테스트를 증명하면 같은 파일을 여러 행에서 골라도 됩니다. 번들 JSON은 원본 파일들과 같은 폴더로 옮겨 판정하세요.

3. 측정값 입력

빈 객체는 통과하지 않습니다. 로그를 보고 실제 측정값만 입력하세요. 필드 계약은 RUNTIME_ACCEPTANCE_PLAN_v2.16과 runtime_acceptance.py가 정본입니다.

4. 생성·검사

아직 생성하지 않았습니다.

실제 서버·실기기·독립 사용자 증거가 없으면 출시 준비로 승격되지 않습니다.
