GCP 비용 확인 도우미

VM을 만들기 전에 “무료 VM이면 VPN도 무료인가?”를 숫자로 확인합니다. 이 파일은 계산과 체크만 하며 Google 계정에 접속하거나 결제·배포를 실행하지 않습니다.

저장 상태 확인 중
입력은 이 화면에서 먼저 유지됩니다.
비밀번호·결제수단·Billing Account ID·토큰은 입력하지 마세요. 프로젝트 ID, 화면에 보이는 비용·통화·크레딧 상태만 기록합니다. 예산 알림은 강제 지출 상한이 아닙니다.

1. 사용량으로 비용 하한 계산

공식 공개 가격 스냅샷(__PRICE_DATE__)을 사용합니다. 계정별 할인·세금·환율은 포함하지 않습니다.

실제 청구 환율이 아닌 비교용 입력입니다.
비밀값이 아니지만 내보낼 파일의 공개 범위를 확인하세요.

2. 로그인된 콘솔에서 확인

화면에서 직접 확인한 뒤 체크합니다. 체크 자체는 서버 생성 승인이 아닙니다.

3. 계정별 확인값

결제수단 번호는 입력하지 않습니다.
아직 생성 금지콘솔 확인 6개와 계정별 값이 남았습니다.

저장·복구 원칙

  • 브라우저 저장이 되면 이 기기에만 자동 저장합니다.
  • 저장이 차단돼도 현재 입력은 화면 메모리에 남고 계산·내보내기는 계속됩니다.
  • JSON 내보내기로 직접 백업하고, 가져오기 실패 시 기존 입력은 바꾸지 않습니다.
  • HTTPS 또는 localhost가 아니면 설치 기능이 동작하지 않을 수 있습니다. 로컬 파일은 웹앱처럼 설치됐다고 간주하지 않습니다.

공식 근거: Google Cloud Free Tier · VPC 가격. 공개 가격은 바뀔 수 있으며 최종 판단은 로그인된 콘솔 표시가 우선입니다. 공개 URL이 없는 로컬 도우미라 QR은 발행하지 않았습니다.
