# FreeFlexVPN 약관·개인정보·국외이전 초안 팩 v0.1

> **상태: 공개·동의 수집·서비스 적용 금지**  
> 이 문서는 개발 준비용 초안이며 법률 자문이 아니다. `[확정 필요]` 항목이 하나라도 남아 있으면 공개하거나 이용자 동의를 받는 문서로 사용할 수 없다. 실제 사업자·서버·결제·보존 설정이 확정된 뒤 한국 개인정보 전문가의 검토를 받아야 한다.

## 0. 지금 확인된 사실과 아직 모르는 것

### 현재 공개 화면에서 확인된 것

- 현재 공개본은 실제 VPN 서버·계정·결제를 제공하지 않는 화면 체험판이다.
- 공개본의 API 주소는 비어 있어 FreeFlexVPN 제어 서버로 요청하지 않는다.
- 현재 국가·목적 국가·사용 순간 검색은 화면 메모리에서만 사용한다.
- PC 앱 화면 모드 선택값과 설치 안내를 닫은 시각은 브라우저 저장소에 남을 수 있다. 저장이 막히면 메모리로만 유지하고 화면은 멈추지 않는다.
- 미래 API가 연결되면 로그인 토큰은 브라우저 세션 범위 또는 메모리에 두도록 구현되어 있다.
- WireGuard 개인키는 사용자 기기에서 생성하고 외부로 보내지 않는 것이 제품 계약이다. 서버에는 공개키만 전달한다.
- 방문 사이트·콘텐츠·DNS 질의 원문은 수집하지 않는 것이 현재 설계다.

# 문서 A. 이용약관 초안

## 제1조 목적과 현재 서비스 상태

이 약관은 `[사업자명 확정 필요]`가 제공할 FreeFlexVPN 서비스의 이용 조건을 정하기 위한 초안이다. 현재 공개 화면은 기능 체험용이며 실제 VPN 연결·계정·결제는 제공하지 않는다. 정식 서비스 개시일과 제공 국가는 별도로 고지한다.

## 제2조 쉬운 용어

- **FreeFlexVPN 앱 화면**: 국가·기기·잔액·사용량을 보고 설정을 받는 웹 앱
- **WireGuard 앱**: 실제 VPN 터널 연결을 담당하는 공식 클라이언트
- **무료 데이터**: 매월 제공 예정인 무료 사용량. 현재 제품 기준은 월 1GB이나 정식 약관 채택 시 다시 확정한다.
- **충전 데이터**: 이용자가 별도 결제로 구매하는 사용량. 현재 제품 계약은 미사용 충전분 무기한 보존이나, 결제·회계·서비스 종료 정책 확정 전에는 판매하지 않는다.

## 제3조 가입과 계정

1. 실제 가입 방식은 `[Telegram/이메일/그 밖의 방식 확정 필요]`이다.
2. 서비스는 가능한 범위에서 가명 계정 식별자를 사용한다.
3. 이용자는 수령 링크·세션 토큰·기기 설정을 타인에게 넘기지 않아야 한다.
4. 만 14세 미만 이용 정책은 `[확정 필요]`이며 확정 전에는 가입을 받지 않는다.

## 제4조 제공 기능

1. 실제 서버가 준비된 국가의 VPN 연결
2. 기기별 WireGuard 공개키 등록·폐기
3. 무료·충전·보상 데이터 잔액과 사용량 확인
4. 추천 토큰 발급과 조건 충족 시 보상
5. 장애·보호 상태·설정 실패의 정직한 고지

서버가 없거나 안전 검사가 끝나지 않은 국가는 선택 또는 연결을 비활성으로 표시한다. 특정 스트리밍 서비스, 검열 우회, 항상 가장 빠른 서버, 완전한 익명성은 보장하지 않는다.

## 제5조 금지 행위

다음 행위는 제한할 수 있다.

- 스팸·피싱·악성코드·계정 탈취·불법 침입
- 타인의 권리 침해 또는 법령 위반
- 서비스 안정성을 해치는 자동화 공격
- 계정·추천·무료량을 부정하게 반복 생성하는 행위
- 대량 메일 발송이나 명백한 파일공유 남용 등 사전에 고지한 안전 제한 우회

제한 기준, 소명 방법, 이의제기 연락처는 `[확정 필요]`다. 자동 차단만으로 영구 제재를 확정하지 않도록 운영 절차를 마련한다.

## 제6조 무료량·충전·보상

1. 무료량·차감 순서·보상 조건은 앱에서 결제 전에 보여준다.
2. 현재 설계는 무료량을 먼저 사용하고 충전 잔액을 뒤에 사용한다.
3. 충전 가격, 세금 포함 여부, 결제수단, 환불 조건은 `[PG 계약 및 전문가 검토 후 확정 필요]`다.
4. 실제 결제·환불 왕복 검사가 통과하기 전에는 유료 판매를 시작하지 않는다.
5. 잔액 오류가 확인되면 추가 차감을 멈추고 원장과 결제 증거를 대조한다.

## 제7조 기기 설정과 보안

1. WireGuard 개인키는 이용자 기기에서 생성하고 서비스는 공개키만 받는다.
2. 이용자는 기기 분실 시 등록 공개키를 폐기할 수 있다.
3. 실제 보호 상태는 연결 버튼 모양이 아니라 터널·출구 IP·DNS·IPv6 검사를 기준으로 판단한다.
4. 운영체제별 안전 검사 완료 전에는 정식 지원으로 표시하지 않는다.

## 제8조 서비스 중단·변경·종료

점검·장애·공급자 문제·보안 대응으로 서비스가 중단될 수 있다. 중단 사실과 영향을 알 수 있는 범위에서 고지한다. 서비스 종료 시 미사용 충전 데이터의 환불 또는 이전 방법과 고지 기간은 `[확정 필요]`다.

## 제9조 책임과 분쟁

법이 허용하지 않는 책임을 약관으로 배제하지 않는다. 손해배상 한도, 준거법, 관할, 소비자 분쟁 처리 절차는 `[한국 법률 전문가 검토 후 확정 필요]`다.

## 2. 처리 근거

각 항목의 계약 이행, 동의, 법정 의무 등 처리 근거는 실제 가입·결제 흐름 확정 후 항목별로 표시한다. 지금은 처리 근거가 확정되지 않았으므로 이 초안으로 동의를 받지 않는다.

## 3. 제3자 제공과 처리위탁

현재 확정된 제3자 제공은 없다. 호스팅·클라우드·고객지원·메시징·결제 사업자가 확정되면 법인명, 위탁 업무, 항목, 기간, 재위탁 통제를 표로 공개한다. 단순한 제품명이나 “클라우드 업체”라는 표현만으로 게시하지 않는다.

## 4. 파기

목적 달성 또는 보유기간 종료 시 복구하기 어려운 방법으로 파기한다. 계정 DB, 백업, 로그, 결제 원장의 실제 파기 주기와 예외 보존 근거는 `[확정 필요]`다. WireGuard 개인키는 서비스가 보유하지 않는 구조를 유지한다.

## 5. 이용자 권리

이용자는 법이 정한 범위에서 열람·정정·삭제·처리정지·동의 철회와 탈퇴를 요청할 수 있다. 앱에서 기기 공개키 폐기, 계정·추천 토큰 삭제 요청, 잔액·결제 내역 내보내기 경로를 제공할 계획이다. 실제 접수 URL, 이메일, 처리기한, 본인확인 방법은 `[확정 필요]`다.

국외이전이 계약 이행에 필요한 처리위탁·보관에 해당해 처리방침 공개 또는 개별 알림을 근거로 삼는 경우에도, 이전받는 자·국가·항목·목적·기간·방법과 거부 방법 및 효과를 실제 값으로 공개해야 한다. 별도 동의가 필요한 경로와 계약 이행 경로를 한 문장으로 뭉개지 않는다.
