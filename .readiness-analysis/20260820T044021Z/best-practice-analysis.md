# FreeFlexVPN 서비스 유사도·우수 관행 자동 분석

분석일: 2026-08-20
분석 모드: 읽기 전용. 이 폴더 밖의 제품 코드·설정·배포·Git 저장 기록은 변경하지 않았다.

## 1. 분석 범위와 방법

대상은 현재 열려 있는 `FreeFlexVPN-Source` 작업 폴더뿐이다. 내장 500개 서비스 도메인에서 가장 가까운 분야를 고르고, 공개 경쟁 서비스의 **공식** 문서를 외부 근거로 삼았다. 이후 프로젝트 코드·기존 자동 검사·공개 URL·대시보드의 증거를 `crh-project-evidence/v1`에 보수적으로 입력하고 CRH 엔진 1.0.1을 실행했다.

근거 표기: **[확인]** 실행·외부 응답·자동 검사로 확인, **[추정]** 코드/문서 해석 또는 모델 산출, **[미확인]** 증거가 없거나 실제 운영/기기에서 확인하지 않음.

## 2. 서비스 프로필

FreeFlexVPN은 공용 Wi-Fi·여행·해외 체류 상황에서 안전한 연결과 체험/사용량 정보를 제공하려는 소비자 VPN/PWA 준비 프로젝트다. 공개 정적 앱과 반응형 UI는 [확인]이지만, 실제 VPN 접속망, Android 네이티브 설치, 결제, 고객지원 운영, 법률 검토는 [미확인]이다. 분석 엔진 방향값은 소비자형·한국에서 글로벌 확장·무결제·모바일/웹 동등·폐쇄 베타·고민감 정보·소규모 팀·UX 차별·3개월 목표로 설정했다. 이 값은 실제 사업 결정이 아니라 현 저장소의 흔적을 바탕으로 한 [추정] 분류다.

## 5. 리더 사례에서 추출한 우수 관행

1. **연결 보호의 효과와 한계를 함께 설명한다.** Proton과 NordVPN은 Kill Switch/Always-on을 별도 도움말로 다룬다. FreeFlexVPN도 “보호됨” 표기만 하지 말고, 연결 끊김·해제·복구 때의 상태와 사용자가 할 일을 분리해야 한다. [추정]
2. **프로토콜·구성·복구를 지원 문서로 분리한다.** Proton의 WireGuard 구성 문서와 Mullvad의 구성 안내는 고급 설정이 일반 UI와 다른 지원 경로를 필요로 함을 보여 준다. FreeFlexVPN의 실제 터널이 준비된 뒤 동일한 운영 문서가 필요하다. [추정]
3. **금전 조건을 제품 흐름에 맞춰 명시한다.** Proton의 플랜 문서와 Mullvad의 환불 문서는 체험·기기 수·환불 조건을 사용자가 실행 가능한 수준으로 고지한다. FreeFlexVPN에는 실결제·환불 처리 증거가 없다. [미확인]
4. **운영 문서도 제품 기능이다.** Mullvad의 도움말은 연결 점검과 지원 경로를 제공한다. 장애 중인 사용자가 앱 안에서 해결하지 못할 때의 지원·공지·재현 정보가 필요하다. [추정]

## 6. 이상 기준(18개) 요약

상세 기준은 `ideal-standard.json`에 있다. 우선순위가 가장 높은 항목은 (a) 실제 상태의 정직한 표시, (b) 프로토콜/연결 복구, (c) Kill Switch/Always-on 제약 고지, (d) 실제 터널 상태와 UI 일치, (e) DNS/IPv6 누수 점검, (f) 실사용 성능·오류 관측, (g) 배포 보안, (h) 개인정보·삭제·국외 이전의 실제 처리, (i) 가격·환불·영수증 종단 흐름, (j) 단일 유휴 Android 기기 시험이다.

18개 중 현재 [확인]은 자동 검사·공개 HTTPS·문서 존재에 한정된다. 실제 VPN 품질·보안성·법규 준수·상용 운영을 “확인됨”으로 판정한 항목은 없다.

## 9. 시장 상대 위치 해석

엔진은 기능 폭·UX·성능·신뢰·도달·가격·수익모델·현지화 8개 차원을 비교했다. FreeFlexVPN은 한국어 UI에 관한 현지화 가설에서는 일부 상대값이 있으나, 신뢰·도달·가격·수익모델은 실운영 증거가 없어 낮게 입력됐다. 기능·UX·성능 차원도 많은 값이 프로젝트 준비도에서 자동 유도되며 증거 범위가 낮다. 따라서 “16.67%”는 외부 시장에서의 실제 순위가 아니라 **현재 증거 패키지의 비교 위치**다. [추정]

이 분석은 독립 보안 감사, 법률 자문, 침투 시험, 실제 결제, 실제 고객 데이터, 실제 VPN 접속망을 대체하지 않는다. 검색·광고·이용자 생성 콘텐츠 도메인은 현재 VPN/PWA 핵심 범위가 아니므로 개선 점수에 억지로 포함하지 않았다. 다만 추후 광고·커뮤니티·개인화 검색을 도입하면 해당 렌즈를 다시 평가해야 한다.

## 15. 다음 자동 실행 가능 작업

분석 이후 개발을 허용받는 별도 작업에서만 다음을 자동화할 수 있다: 공개 URL의 보안 헤더/깨진 링크/robots·sitemap 검사, 릴리스·롤백 문서 대조, 브라우저 폭·키보드 회귀 검사 확대, 비밀값·의존성 점검 결과 정리, 성능 예산/측정 대시보드 설계, 지원 문서 초안, VPN 연결 상태 모델의 자동 단위/통합 시험 추가. 실제 결제·법률·운영 신원·기기 시험은 자동화만으로 완료 처리하면 안 된다.

## 16. 사업자 또는 운영자 결정이 필요한 항목

- 실제 VPN 인프라 제공 주체, 대상 국가, 연결 제한과 합법적 사용 범위
